# SRT Clip C2 Universal 0.4.7

插件包与 Skill 版本：**0.4.47**；业务内核：**0.4.7**。支持抖音电商经营咨询与 SRT 文案剪辑。咨询规则见 `skills/srt-clip-c2/references/commerce-advisory.md`；SRT 执行从 `skills/srt-clip-c2/SKILL.md` 进入。

- 电商咨询区分已知事实、推断与待核实项，给出有排序的优先建议、可直接使用的内容或可观察指标；重大既有工作流调整先给完整方案并等确认。涉及最新平台规则时按需核对官方权威来源。
- 多商品先确认目标商品；完整信息池完成后展示全部通过质量门槛且实质不同的开头候选，由用户选择；选择几个就生成几条独立成片，每条从对应开头开始。
- 每条成片先完整覆盖有效卖点和必要支持，再开放划分、动态排序完整内容板块；不跨板块穿插。90 秒为目标，超过 90 秒比较板块增量，100 秒为可接受参考，超过 100 秒逐条复核且不自动截断。
- 直接行动型与种草/推荐型促单独立分类，适用且合规的完整原话置于最后板块；结尾动态交易信息无活动例外，促单绝对化表达照常审核。
- 正式词库按字段范围逐项执行；命中时仅排除完整字幕句。最终核对原话、商品归属、序号及时长，固定五部分交付。

日常 SRT 剪辑不调用 Python、脚本、CLI 或 JSON 流水线；这些工具仅供开发、构建和发布验证。
