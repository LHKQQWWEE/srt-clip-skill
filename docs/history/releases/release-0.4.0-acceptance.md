# C2 Universal 0.4.0｜发布验收记录

## 基准与变更

- 唯一业务基准：实际读取的已安装插件 **0.3.20**。起始时 GitHub main 为 **0.3.19**，仅作为待同步的旧发布面。
- 0.4.0 把单一功能身份扩展为组织式职责架构：宪章、总决策编辑、商品购买决策架构师、商品事实与边界官、购买决策剪辑师、成片质量审计官。
- 一个 AI 在一次语义分析中承担逻辑职责；成片审计仍是已有的一次终检，发现问题时只作局部修复。没有新增模型、Agent、分析轮次、职责台账、JSON、Python 或环境门槛。
- 内容路径由商品、顾客决策、原话证据、适用条件和独立购买理由动态构建。移除了固定类目路由；商品知识包仅保留事实提醒、证据边界和归属风险。未登记商品类别仍可执行。
- 保留 SRT 与逐条时长文本、原话和来源约束、全局禁令、1.2 倍速预计45–120秒、固定五部分输出、Long Context 规则。
- 本轮未修改全局禁用词的词项或扩展范围。

## 真实文本语义测试

使用用户此前提供的一份**656条、多商品直播字幕**作本地语义回归；原始文件和逐条字幕没有打包或提交到公开仓库。

- 测试目标：首个鞋类窗口（原始字幕 1–149）；后续服装和其他商品不与目标鞋混编。
- 动态路径：以鞋型视觉结果（19–27）进入，接上颜色搭配（34–38），再按常规尺码、窄脚半码和宽/肉脚的条件编排（102–103、105、140–147、149）。结构由当前字幕中的顾客选择问题决定，没有采用材质优先模板。
- 事实与边界官：排除全羊毛禁用声明（如 11、14–16、64、122）；不采用品牌归属不清的表达（如 5–9、120）；实时尺码/库存、价格和直播 CTA 不进入成片。第47条的“防滑”功能未有独立资料佐证，本次不把它当作已核实事实或用来补时长。
- 原话剪辑师选取25条原始字幕：19,20,21,22,23,24,25,26,27,34,35,36,37,38,102,103,105,140,141,143,144,145,146,147,149。时长合计 **43.190秒原始时长**，预计1.2倍速 **35.992秒**。
- 质量审计判定：商品归属、禁用表达、动态交易信息、原话和条件边界通过；预计不足45秒，因此只能标记为“短候选，非正式成片”，不加入弱卖点或重复片段凑时长。该测试验证的是字幕语义编排，不代表画面、材质、功能或平台审核已核验。
