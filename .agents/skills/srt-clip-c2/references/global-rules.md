# 全局禁用规则｜所有商品唯一执行入口

本文件是全商品通用的用户剪辑禁用库，也是**唯一正式违禁词库**，女装、鞋、围巾、童装及其他商品统一执行。总决策编辑是词库管理负责人；不得豁免已确认规则，也不得自行增词、扩展别名或扩大语境。正式词库仅按用户明确确认的表达维护。

未在本表明确登记的词条、等价表达和例外均未获授权；不得扩大到未授权的近似表达或材质类别。

正式违禁词拦截、上下文审核和未入库风险提示分开处理。日常任务离线执行，不自动联网扩词。价格、库存、功效等另按现有平台合规边界和素材时效规则判断，本词库不覆盖这些规则。

## 命中、保护与扫描顺序

- 本轮完整执行顺序：**原始 SRT 扫描 → 违禁句过滤 → 卖点信息池建立 → 板块编排 → 最终成片复扫 → 序号核验**。原始扫描和语境判断完成后先过滤命中字幕，再建立卖点信息池。最终复扫覆盖字幕、标题、话题和正文；命中过滤的原始序号不得在后续编排或复修中重新进入成片。
- 促单语境不构成豁免。促单句内出现正式直接词条，或语境审核确认属于商品绝对化宣传时，仍须处理命中的完整字幕句。
- “不易起球”是本轮明确允许表达，必须先做完整表达判断，不能因它与“不起球”存在部分字面相似就误拦截。未确认的相似说法不自动加入白名单。
- 防静电不是正式禁词；商品事实或语境不清时仅标待核，不因它靠近正式词条而拦截。
- 只按单条字幕句判断并排除完整命中的字幕句，准确保留原始序号；不得把相邻字幕拼成一个命中，也不得扩展到前后字幕、整段内容或其他商品窗口。上下文只供语义和归属判断，不扩大拦截范围。命中句不得删字、改写或以改写句重新加入。
- 多商品字幕逐句核对商品归属。某条混合提及多个商品的字幕本身命中时整条排除；其他商品的相邻字幕保留，不因这条命中连带删除。
- ASR 疑似转写、谐音、简称和错字不自动算正式命中，也不自动成为词库别名。分别记录为：**明确命中**、**已确认等价表达**、**疑似风险/疑似 ASR**、**无法确定**。疑似风险和无法确定只提示或待回听，不自动拦截；无法确定不进入成片前须按具体任务标待核。
- 未入库的语义相似表达、材质类别或上下文只可作风险提示；语义等价仅限词库登记的正式表达和表中明确列出的已确认等价改写，不得扩展到整个词语类别、材质类别或上下文。
- 标题、话题和最终成片同样执行正式词库复扫；标题与话题按对应字段规则处理，正文不因仅有字段禁用词而删除字幕。
- 价格本身不是本词库的违禁词命中。来源可核验且对应当前商品/SKU 的真实标价可在主体正文保留；结尾促单价格继续按 `references/editorial-policy.md` 的动态交易信息规则处理，禁词模块不得覆盖或放宽该规则。

## 字段特例

- **“羽绒服”**：所有商品的生成标题与话题禁用；正文原话及商品识别不因此删除。
- **“鹅绒服”**：所有商品的生成标题与话题禁用；正文（包括原话字幕及成片正文）和商品识别可正常使用，不因该词排除字幕。仅按完整词组“鹅绒服”执行，不扩展到“鹅绒”或其他近似表达；不纳入直接字幕匹配词表。
- 其他新增禁用词句，除用户明确限定字段外，默认对入选字幕原话、生成标题、话题统一生效。
- 每版仍输出一个标题和五个相关话题；具体话题由总决策编辑根据当前商品和成片真实主线动态生成，商品知识包不设固定话题。

## 上下文风险提示与维护边界

- 每次处理先检查本文件正式词库。直接词条按标准化字面匹配；语境词条逐句判断商品归属和主张；日常执行不调用脚本或外部工具，开发脚本只验证机械边界。
- 未入正式词库但有风险的表达，仅结合当前商品、具体主张、原话和可用依据提示待核；不自动加入词库、不直接删除整段或相邻字幕。风险提示既不是违规认定，也不是合规结论。
- 商品工艺描述按具体事实判断；不能因相近关键词或肯定语气扩展词库。事实不足时提示核实，不升级为正式禁词。
- 用户明确新增词条时，严格按其给出的表达、语境和例外记录来源、测试案例及版本变更；不得自行补入近义词、ASR 变体或白名单。用户没有确认的变体仅作风险提示。
- 全局禁令是用户内部剪辑选择标准，不替代平台当次审核判断；不提供规避审核的改写。
