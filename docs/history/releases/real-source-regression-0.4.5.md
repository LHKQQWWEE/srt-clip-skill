## 卖点覆盖压力控制组（合成，不是新增真实素材）

本控制组检查“低决策价值是否会被时长压力删除”，不冒充真实直播原文，也不替代上表的真实素材。历史上另做过一组 0.4.4 合成短款大衣压力审核；其提示了低价值与弱增量被混为一谈的问题，但与下方本轮的 13 项控制输入不构成严格的一对一时长对照。

- 0.4.4 合成审核在约 45 秒、1.2 倍速目标下选择了 `[6, 1, 2, 4, 7, 8, 9, 11, 12, 13]`，原时长 57 秒、加速后约 47.5 秒。它省略颜色/真牛角扣信息（编号 10，理由是决策价值较低），并省略设计结论与轻盈信息（编号 3、5，判断为相邻内容重复/已覆盖）。这仅是历史合成审核观察，不是对真实大衣素材的结果。
- 本轮 0.4.5 同题型合成审计在完整候选中保留全部 13 项，按顺序为 `[1/6, 2/8, 3/5, 4/9, 5/3, 6/10, 7/1, 8/11, 9/2, 10/7, 11/12, 12/13, 13/14]`；原字幕序号顺序为 `[6, 8, 5, 9, 3, 10, 1, 11, 2, 7, 12, 13, 14]`。累计原始时长 56 秒，按 1.2 倍速估算 46.667 秒。
- 粒度判断：2/8 与 3/5 合并表达背后小花苞细节；12/13 和 13/14 分别作为各自搭配信息内的例子；1/6 与 10/7 均保留，因为后者另含 V 领和新中式信息。按题设假定，“真牛角扣”信息纳入覆盖；本轮没有独立核验材质证明。
- 结论：45 秒是一般下限参考，不是删点门槛；略超目标不能成为漏掉有效独立信息的理由。测试属于基于当前 Skill 的独立文本压力审计，不是程序测试，也不验证视频、产品证明或平台合规。
