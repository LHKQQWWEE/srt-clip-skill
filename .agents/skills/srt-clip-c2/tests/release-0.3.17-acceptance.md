## 真实文本语义验收

使用用户私有历史会话中的真实逐条时长文本进行模型语义复核；不在仓库保存原始字幕、编号、选段范围或可复原商品标识。以下属于人工语义验收，不是程序自动评分。

1. **多卖点女装文本，默认一条**：比较版型/身形适配、颜色与肤色选择、重量厚薄和外套叠穿等独立决策信息。单条围绕有足够后续原话支撑的强购买理由组织，再按自然承接和时长加入其他有效信息；未发现需要用弱搭配或重复话术补满覆盖的情况。
2. **同一文本，请求两条**：分别围绕版型适配与颜色/肤色选择。两版的中段、购买理由及选择路径均不同，不是只更换第一句；只共享必要的目标商品承接。
3. **同一文本，请求三条**：增加轻重量/厚薄与外套叠穿适配方向，提供另一类使用决策价值；不复制前两版主体，也不为制造差异删除强购买理由。原字幕中的重量、材质等主播陈述未作商品资料或实物验证。
4. **少卖点压力片段**：在真实围脖文本中单独评估只有重复保暖表达的局部片段；这不是对整份围脖素材的整体评价。重复表达归为一个购买理由。请求两条或三条时，这个局部仅能支撑一条成立方案，应说明素材限制，不变换开头或塞入弱搭配/成交内容凑数。
5. **合规边界**：女装文本按当前全局库对确认命中表达作语义判断并排除完整原始字幕项；不拆句保留同项中的其他内容，也不把相近材质词根一律扩成禁令。其他商品与动态交易信息不混入目标片段。

语义验收通过：单条没有为覆盖率牺牲节奏，多条主体/决策理由有实际差异，素材稀少时优先方案成立度而非名义数量。此结论不证明商品事实、材质资料、音画、平台审核、跨模型一致性、投放转化或完整剪辑导出效果。
