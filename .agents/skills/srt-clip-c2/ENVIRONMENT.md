# C2 Universal 0.4.7｜运行环境

- 日常 SRT 任务由当前 AI 宿主读取文本，不调用 Python、脚本、CLI、第三方依赖、联网或远程服务；Python 仅供开发、构建和测试使用。
- 一个 AI 在一次语义分析和现有一次终检中完成判断；不新增 AI、Agent 或语义轮次。
- 多商品先列商品和原始讲解窗口并等待用户选商品；随后只为所选商品生成开头候选。完整信息池后展示所有达到现有质量门槛且彼此实质不同的候选，不设候选数量上限；每个仅含方案名、开头原话、原始序号、预估时长，不遗漏合格候选、不包装重复候选、不预选或凑数。用户最多选择三个；超出时暂停并要求重选。每个已选开头各生成独立完整成片，逐条覆盖全部有效卖点。
- 全量信息池完成后才比较开头；合格观看动力驱动候选优先，仅无此候选时才回退到其他有效钩子；保留动态归类、前 2 秒与前 5 秒连续判断、默认 1.2 倍速下 2.4/6 秒仅作参考、不硬截及其他既有有效规则。
- 先完整编排后计算时长。只有明显超过 120 秒才动态筛选；轻微超时或必要购买信息应保留，必要时可以适度超过 120 秒。
- 适用且合规的原文促单完整保留；没有原文时不编造、改写或补充。
- 日常执行不创建或刷新 JSON 摘要。
- 不可变序号/原话/时长映射逐条对照是硬门；第五部分序号须与成片正文完全一致，否则阻断交付。最终终检只针对实际选定并写出的成片；正式交付保持固定五部分。
- 不包含 MP4 解码、ASR 或音画核验能力；未实际查看的视频、商品资料或剪辑导出不能声称已核实。
