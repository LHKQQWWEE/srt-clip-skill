# srt-clip-c2｜直播切片文案 C2 0.2.0

本插件把 SRT 与视频切片工作流合并为一套现行规则。触发词为：**切片文案、srt文案、srt切片文案、str文案、C2完整精简版**。

## 输入路径

- **SRT / 逐条时长文本**：保留C2文本快路径，严格核对原话、原序号与来源定位。
- **MP4 + SRT**：先完整分析SRT，再对所有最终候选片段和必要歧义区间定向核验视频；不默认逐帧通览整段视频。
- **MP4-only**：只有当前宿主实际能读取口播、画面和时间定位时才制作；没有可靠SRT序号时不生成序号，无法可靠听辨时请用户提供SRT或带时间码的原话。

MP4本身不会自动启用语音识别或解码服务。技能只报告当前环境实际读取到的音画范围。视频不可读但SRT可靠时，可继续按SRT交付并明确画面/原声待核实。

## 时长与开头

统一按全部入选素材以1.2倍速播放后的预计成片45–90秒执行，质量允许时尽量接近70秒；原始素材定位保持1.0倍口径。开头优先复盘最终成片的5秒完播率；5秒是优化目标，不截断完整口播。

## 输出与真实性

固定五部分输出。保留完整原话；视频核验等级严格依据实际听辨和画面检查。长文本或程序核验请求使用随附SRT脚本；脚本不解析MP4。入选原话、来源时间、序号及合规提示都不得臆造。

## 长文本选段收口

长附件先扫描原文件一次，不预先输出全文；截断时从同一快照分页。目标已明确就直接使用。完整清单只做一轮语义筛选，确定一套方案；达到质量和时长门槛后冻结，只有用户改目标或出现具体核验错误时才返工。不要枚举所有组合或反复追求“可能更好”的版本。完整字段结构与例外条件见 Skill。
