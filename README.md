一个 AI 完成语义分析和现有一次终检。多商品先列商品身份与讲解窗口并等待用户选择，再完整读取所选商品并建立信息池；目标明确或单商品时跳过商品选择。

- 钩子与必要紧邻承接联合编排，综合判断前 2 秒吸引力和前 5 秒连续吸引力。默认 1.2 倍速对应原素材累计约 2.4 秒、6 秒，仅作判断参考、不硬截原话。承接随素材动态增强情绪、视觉期待、种草兴趣或购买收益，不固定类型、顺序、权重或评分；不比较完整成片。
- 完整信息池后列出至多 3 个开头候选，每个只含方案名、开头原话、原始 SRT 序号和预估时长，不预选、不代选、不凑数。用户选择后每个开头各生成独立完整成片；每条独立覆盖完整有效卖点与必要支持。
- 先完整编排各方案，再计算时长。120 秒不是目标或硬上限；未明显超时保留全部有效卖点，明显超时才按该方案核心动态筛选并说明省略项。
- 适用且合规的原文促单必须完整保留；原文没有时，不编造、改写、补充或跨商品移用。动态交易内容仍按全局规则处理。
- 不可变原始序号/原话/时长映射必须与成片正文和第五部分序号逐项一致，错误或无法核实即阻断交付。
- 最终终检只检查实际写出的成片；保留其他有效业务规则和固定五部分输出。
