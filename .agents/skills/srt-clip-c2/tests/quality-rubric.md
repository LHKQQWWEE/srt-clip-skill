# C2 Universal 0.3.20｜质量验收标准

本标准用于版本验收和开发期回归，按当前 `SKILL.md` 与有效 `references/` 判断；不构成日常剪辑任务的额外流程。

## 硬性失败项

任一项实质失败即不通过：

- 原话被擅自改写、补造或不连续拼接；商品归属/款式串用；字幕编号、来源或时间伪造。
- 开头弱候选仅凭先后位置或表面完整度压过明显更强、可信且可兑现的顾客结果；老粉限定表达被误当陌生顾客通用利益。
- 购买理由尚未成立就以弱逼单替代证明/适配信息，或忽略更自然、低阻力且能推进购买决定的原话。
- 素材仍有可自然加入的有效高/中决策价值信息，成片低于45秒却直接按正式成片交付；或为凑45秒灌入重复夸赞、弱逼单、普通过渡及无新增信息。
- 合规、归属清楚、独立且可在时长范围内成立的高决策价值亮点无理由遗漏；120秒硬限制下的取舍未说明真实原因。
- 90–120秒没有仍值得保留的独立高决策价值信息，或正式方案超过120秒。
- 明确要求多条时，仅更换开头而购买路径和主体同质，没有新增购买决策价值。
- 动态交易信息或全局禁用表述被错误保留；禁用范围被擅自扩大；缺少证明被误称已知虚假或平台拒审。
- 声称运行了未执行的程序、完整读取了未读文件或核验了未读取的视频；固定五部分输出实质缺失。

## 质量评分（100分）

| 指标 | 权重 |
|---|---:|
| 陌生顾客首屏价值与强候选裁决 | 20 |
| 高价值购买理由覆盖与单位时间购买决策价值 | 20 |
| 第一次购买决策闭环与低阻力自然成交 | 15 |
| 多条方案的购买决策路径互补 | 10 |
| 商品识别与窗口/款式归属 | 10 |
| 原话、必要条件与来源序号准确性 | 10 |
| 正式成片45–120秒及取舍说明 | 5 |
| 合规风险判断 | 5 |
| 五部分输出格式 | 5 |
| **总分** | **100** |

建议通过线：90分，且全部硬性失败项通过。平均分不能抵消硬性失败。

## 首屏与购买决策结构

- 陌生顾客首屏价值测试优先判断明确收益；强结果候选不能被没有明确顾客结果的颜色、普通搭配、泛材质或泛泛介绍仅凭完整度压过。
- 开头按 Universal Core 的统一顺序比较顾客收益、具体可信、承接兑现、差异性和表达完整度；差异性加分但不是门槛。
- 中段构成购买决策链；每段承担新增理由、证明、顾虑回应、适配/选择帮助、决策推进或必要承接。按单位时间购买决策价值评价信息密度。
- 首次成交发生在购买理由成立之后，优先选择自然、低阻力且对目标顾客有决策帮助的原话。首次成交后仍继续考虑尚未使用的高决策价值独立理由。

## 价值层级、单条和多条

- 高/中/弱增量根据具体商品、顾客和文本动态判断；不以类别代替购买价值，不设覆盖率百分比。
- 单条正式方案中，合规、归属明确、可在时长内成立的高价值独立理由不得无理由遗漏；低价值补充若损害节奏可舍弃，不能靠堆满来增加覆盖。
- 多条方案各自独立成立、购买路径实质互补；核心理由可共享，次要理由优先匹配。只换开头不算实质差异；不为互补或凑数削弱强方案。

## AI-First 与验证报告边界

- 所有语义决策归 AI；工具只可辅助读取、定位、计算和格式检查。
- 只要文本可可靠读取，工具不可用不阻断核心任务；日常任务不要求 Python、JSON、网络、额外模型轮次或环境自检。
- 测试记录分别标出静态规则检查、AI 对测试文本的语义回归、实际程序执行和跨平台验证。未实际执行的项标记“未验证”，不得推断通过。
