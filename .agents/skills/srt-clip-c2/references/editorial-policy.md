# Universal Core｜购买决策结构权威

本文件是跨类目开头、中段、首次购买决策闭环与结尾结构的唯一通用规则来源。`SKILL.md` 负责角色、入口与执行边界，`highlight-selection.md` 负责价值层级、信息密度和时长；类目模块只补充真实的商品专项判断。发生冲突时，AI-First Constitution、全局合规规则和本 Universal Core 优先于类目说明。

所有语义判断仍由 AI 在现有一次分析与一次终检中完成；本规则不新增分析阶段、模型轮次、台账或输出字段。

## 陌生顾客首屏价值测试

默认对象是第一次刷到视频、不了解主播和直播背景的顾客。首屏价值测试是同一次编排中的判断：听完候选开头后，顾客能否马上明白商品可能带来的结果、解决的购买/使用问题，或继续看下去的具体理由？

候选必须属于目标商品，原话完整自然，离开直播前情仍可理解，并有同商品原话可以兑现。开头竞争依次优先：**顾客收益 > 具体可信 > 可承接与兑现 > 差异性 > 表达完整度**。这是语义比较顺序，不是打分表；具体可信和后续兑现不能被形式上的新鲜感取代。

- 当强候选在顾客收益、可信度和可兑现性上明显胜过弱候选时，普通颜色、普通搭配、泛材质或完整但泛泛的商品介绍不得仅凭句子完整、先出现或画面依赖而胜过它。
- 颜色、搭配、材质或外观表达不按关键词禁用。若原话本身清楚说出显气色、不沉闷、显瘦、利落等具体顾客结果，并且来源可信、后续能兑现，它可以与其他强候选公平竞争。
- 差异性只加分，不是硬门槛。普遍但具体、可信且有支撑的购买结果仍可胜出。
- 老粉、老顾客、复购用户限定内容默认不代表陌生顾客的利益；只有当前目标受众确实是该人群，或同句也给陌生顾客独立决策价值时，才按实际价值竞争。
- 不把主播回答、个人偏好、一般尺码/搭配建议冒充顾客困扰。顾客困扰须来自顾客原话或主播清楚转述；主播明确确认商品存在的负面表现，依现行专项规则判断，不可反向包装成商品优势。
- 不把动态价格、库存、优惠、直播过渡或链接提示当通用首钩。没有合格候选时，选最清楚且有辨识度的商品事实；仍没有就如实说明，不拼凑开头。

选定入口后，使用最少但足以解释、证明或展示其核心价值的原话。若原素材不能支撑开头，应重新权衡候选；不能靠改写、跨商品拼接或虚构解释补强。开头只决定入口，不把后续内容锁进单一主题。

## 中段购买决策链

中段优先形成自然的**购买决策链，而不是卖点类别堆叠**：前一句建立的结果或事实，引出顾客接下来会问的问题；后一句作必要解释、证明、适配确认或决策简化。可自然使用结果→原因、顾虑→回应、特点→使用价值、属性→场景、版型→身材效果、材质→穿着体验等真实关系，但它们不是模板，也不要求全部出现。

每个片段都应承担至少一种可理解的工作：提出新购买理由、证明现有理由、回应顾虑、帮助适配/选择、降低决策阻力，或完成必要承接。没有新增或承接价值的重复夸赞、普通过渡和脱离上下文的行动口号不因类别齐全而保留。具体价值分层与单位时间信息密度按 `highlight-selection.md` 执行。

主题顺序只决定怎么排，不决定理由留不留。先保证开头得到最小充分兑现，再让剩余独立理由按语义关系进入成片；不因开头主题不同、类别不同或暂时难衔接就删除有效理由。可以重排同一目标商品的原话，但必须保留对象、条件、因果和原意，不跨商品或款式混编。

## 第一次购买决策闭环

第一次成交机会升级为**第一次购买决策闭环**，不以“越早说拍越好”作为标准：

**强开头 → 最小充分证明 → 第一个购买理由成立 → 降低决策阻力 → 第一次自然成交机会。**

- 购买理由尚未成立前，不用“直接拍”“赶紧买”等弱逼单替代证明或适配信息。此时优先补足最小必要解释。
- 购买理由成立后，选择对陌生顾客也成立、自然且低阻力的机会。适配确认、合适人群/尺码说明、款式颜色选择建议或决策简化，若能让顾客更容易判断“适不适合我、选哪个”，通常优先于没有新信息的硬催促。
- 行动引导可以使用，但需承接已成立的理由并自然推进决定。若素材中更早出现的硬 CTA 有充分上下文和真实新增价值，可按实际效果评估；不得因“最早”二字机械选取。
- 第一次闭环完成不等于成片结束。继续编排尚未利用的高决策价值独立理由；后续成交只有提供新增决策/转化价值时才保留。弱成交不得挤占独立购买理由。
- 不设固定成交次数、位置、软硬比例或逼单式结尾。没有自然成交原话时可以不放，不创作字幕中不存在的句子。

## 原话、混合信息与动态交易边界

- 原话逐字保留，只能重排同一商品的完整原话；不润色、改写、补词或拼接不连续片段。命中全局禁令时，依 `global-rules.md` 排除完整原始字幕序号。
- “它/这个/那款”等指代不清时，核对必要前后文；仍不能确认商品归属则不选入正式方案或明确标待核实。疑似转写错误保留原字并标注回听，不代改。
- 具体商品价格、优惠、赠品、直播福利、倒计时、库存/稀缺数量及其他依赖实时交易条件的信息，全片默认排除。只有用户明确要求制作有效期明确的活动素材且确认活动与发布时段仍有效，才对该任务例外；该例外不扩展全局禁令。
- 混合字幕只有在排除动态部分后，仍能逐字保留原始连续、语法完整、语义自足且自然衔接的原话子句时才可使用。仅剩词组或残句就舍弃整条相关字幕；不改写、补词或拼接。命中全局禁令仍排除完整原始序号。
- 购买者反馈只有在来源清楚、原话完整时才能作为候选；主播泛称“大家都喜欢”不等于真实顾客反馈。无法核实的社会证明就地标明，不扩写成普遍结论。
- 安全风险、护理要求或明确不适用条件不能被剪掉后留下相反的无条件承诺；依据不足时按全局合规规则标待核实。
