# SRT Clip C2 Universal 0.4.2｜开始使用

当前唯一执行版本为 **0.4.2**。只使用本目录的 SKILL.md 与其明确引用的当前文件；不从历史副本、旧 portable 或缓存内容加载规则。

## 支持范围

- SRT 文件
- 逐条时长文本

MP4 不属于正式跨平台范围。SRT 与 MP4 同时提供时只按文本剪辑，不声称核验画面或原声；只有 MP4 时，请用户提供文本。

## 四个触发词

srt文案、srt切片文案、str文案、C2完整精简版。通用词“切片文案”不是 C2 触发词。

## 执行原则

一个 AI 在一次语义分析中承担总决策、动态购买决策架构、事实边界和原话编排等逻辑职责，再做现有的一次终检。各职责不是额外 Agent 或串行模型。内容结构按商品、顾客、证据和实际购买理由动态选择；商品知识包只提示事实、条件与归属边界，不提供模板。

用户可能在任意位置离开。完整理由须让陌生顾客理解具体结果/用途/问题，并有足够原话依据与必要条件；孤立属性、宽泛适配词或行动口号不自动触发成交。优先以最小充分购买单元尽早建立理由，再寻找最早合理机会。任何成交信号前移前，核对完整语义、商品/颜色/对象/条件、前置事实和本地语境。低完播检查沿最终顺序的累计语义前缀动态选点，不把前段、前中段、中段变成固定三点。后续新理由可再判断是否成交，但不固定位置、次数或劝买密度；后段主要补充确定性、顾虑和适配/选择，不承担第一次说服。

对重复表达判断信息增量、说服增量及机会成本：删除机械重启，允许有记忆/感染收益的强调，保留增加原因/证据/体验/条件的递进，压缩没有明显增量的过度重复。不得用相似度或固定次数机械删减，也不得让强调挤占更重要独立理由。

正式成片按 1.2 倍速预计 45–120 秒；45–90 秒优先，90–120 秒只在仍有独立高决策价值内容时扩展。素材不足时使用短候选，不灌水。不得为45秒保留无效重复。保留原话、来源、商品归属和必要条件；固定五部分输出。

终检中的低完播压力测试沿实际语义边界检查前段、前中段和中段截断，不用固定秒数或比例。动态价格、优惠、库存、限时、直播专属福利、涨价和稀缺等默认排除，不因成交机会前移而恢复。
