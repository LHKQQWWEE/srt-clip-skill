# SRT Clip C2 Universal 0.4.7｜开始使用

Skill 版本：**0.4.28**；业务内核：**0.4.7**。从本目录的 [SKILL.md](SKILL.md) 进入。先校验持久化版本摘要 `references/execution-summary.json`。首次运行、摘要失效或版本/规则哈希不匹配时完整读取当前规则并刷新；有效摘要可直接复用。缓存可选，丢失不影响有效持久摘要。

## 输入

- 触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。
- 输入为 SRT 或逐条时长文本。只有视频文件时不声称核验未读取的画面或原声。
- 同一 AI 完成一次语义分析和现有一次终检；脚本是可选的机械辅助。

## 规则顺序

完整读取目标商品全部有效窗口并建立卖点池后，按动态顾客心理驱动机制比较真实原话与必要紧邻承接，不设置固定类型优先级、权重或评分。默认直接生成两个具有实质差异和独立购买核心的完整方案，每条独立覆盖完整有效信息池；第二条不能成立或降低质量时只生成一条并说明具体原因。开头指定“单条”或“按推荐版”时直接一条。

先完整编排各方案，再分别计算时长。120 秒不是目标或硬上限；只有明显超过 120 秒才按该方案购买核心动态筛选并逐项说明省略项，必要时可适度超时。适用且合规的原文促单完整保留；没有原文时不补造。最终终检只检查实际写出的成片。

日常正式交付保持固定五部分；正式词库、商品识别、归属、动态结构和原话边界以运行正文为准。
