# Skill 0.4.39｜开头候选数量专项验收

## 验收范围

L2 开头候选数量模块。基准为实际生效 Skill / Plugin 0.4.38，Core 0.4.7，插件 ID 与发布 ID保留。候选质量、开放式观看动力优先级、前 2 秒/前 5 秒联合判断、四项展示格式及独立成片业务规则保持有效。

## 预期与专项结果

- 输入 0 个合格候选：展示 0 个，不补造或凑数，说明无合格候选并等待用户指示。
- 输入 1、3、5、10 个彼此实质不同且通过质量门槛的候选：分别展示 1、3、5、10 个；不因数量截断。
- 用户选择 1 或 3 个：分别生成相同数量的独立完整成片。
- 用户一次选择 4 个：暂停生成并请用户重新选择至多 3 个；不得静默截断或代选。
- 每个候选固定四项；实质相同开头不拆分包装；不预选、不代选、不凑数。

## 自动验证

- 专项候选数量测试通过：0、1、3、5、10 个合格候选分别完整显示；验证每项四字段格式、不得静默截断、用户选择上限及超限暂停。
- 直接关联规则与入口回归通过：13 个定向测试模块，共 86 项测试。
- runtime、执行摘要、便携版及 canonical / `.agents` 双目录镜像均成功构建；两份 Skill 镜像共 86 个文件，并由镜像一致性测试核对。
- 运行源哈希、runtime 清单与版本一致性回归通过。
- GitHub 与当前插件版本的发布读回结果记录在本次交付摘要；本报告随同一份 Skill 0.4.39 源包发布。

候选数量测试使用已标记为“达到门槛且彼此不同”的合成候选，验证候选展示数量流转和用户选择边界；它不替代实际素材上的语义质量判断。

## 旧规则清理

当前有效规则中不保留候选展示数量上限。旧版验收材料移至按版本标识的历史目录；用户最多选择三个的限制保留。
