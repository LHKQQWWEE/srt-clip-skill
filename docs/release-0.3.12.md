# C2 Universal 0.3.12｜发行记录

## 基准与目标

- 基准：C2 Universal 0.3.11，来自当前安装 Skill、当前插件缓存和 GitHub 默认分支的核验。
- 目标：C2 Universal 0.3.12。
- 改动性质：购买理由递进与动态成交编排规则升级；不更改普通任务流程架构。

## 变更范围

- 开头价值需要最小充分支撑；支撑不足时重新权衡开头。
- 购买理由成立后，优先安排最早合理、自然、完整的成交机会；不强制软硬类型、次数、位置或结尾逼单。
- 首次成交后继续选择有独立购买价值的商品信息；后续成交节点必须有新增转化价值。
- 动态交易信息全局默认排除；仅遵循当前规则限定的、用户明确确认的有效期活动例外。
- 混合字幕仅可保留原始连续且完整自然的商品表达；不得改字、补词、拼接非连续内容；现行整条禁词规则继续适用。
- AI 一次性语义筛选与编排、原话与来源序号、商品归属、1.2 倍速 / 120 秒硬上限、类目专项、合规、固定五部分输出均保留。

## AI 主路径、工具与效率

- 普通任务仍由 AI 基于可靠字幕文本完成一次性语义判断和编排；没有新增工具、执行步骤、台账或模型调用轮次。
- 本次开发测试使用 Python 单元测试与人工语义复核，仅用于发行验收；不成为日常任务依赖。
- 未测端到端耗时、工具调用减少幅度或真实转化表现，不声称效率或业务效果提升。

## 验收

静态单元回归 37/37 通过；十项行为验收 10/10 通过，其中 7 项模拟、2 项真实字幕、1 项模拟与真实上下文混合。完整范围、时长算式及未验证边界见 Skill 内 `tests/release-0.3.12-acceptance.md`。本次未验证音视频、真实发布表现、转化率或端到端耗时。
