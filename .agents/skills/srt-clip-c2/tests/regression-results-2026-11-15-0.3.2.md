# C2 Universal 0.3.2｜Long Context / AI-First 增量回归

日期：2026-11-15

## 真实长文本测试 L01

来源：历史 `10月31日.srt`，约996条字幕、3984文本行、约18分10秒。

测试观察：
- 宿主单次全文读取存在安全输出上限，分段读取是必要的机械辅助，但没有使用Python作为语义决策器。
- AI能够从分段素材中识别同一加绒卫裤长时间、多轮重复讲解，并识别后段仍出现新的/更强的卖点表达，例如一体加绒、定制针织棉、立体剪裁、裤兜拉链、束脚防风、裆部加宽、屁股大胯宽适配、短而密的绒、不显臃肿等。
- 后段存在多次“快速总结卖点”窗口，验证了“只读第一次商品窗口”会漏信息，因此必须合并全部离散/重复窗口并反向漏检。
- 价格、库存、倒计时和强促销大量穿插，验证全局扫描需要先做窗口地图，再把动态促销与产品卖点分开。

## 合成压力测试 L02

生成2000条、约2小时结构测试源：多个商品轮换、目标商品4次离散回场、每个窗口包含独有卖点和部分重复强化。

验收目标：
- 第一阶段只建立全局商品窗口地图，不在扫描阶段完成最终成片。
- 目标商品4个窗口全部进入精读。
- 卖点池只建立一次；两条/三条方案共享同一池。
- 同卖点最多两处强化；不同卖点优先覆盖。
- 工具不可用时，流程仍可由AI分块完成。

结构压力检查通过；该测试不冒充跨模型真实语义盲评。

## 结论

0.3.2发布条件：AI-First Constitution、Long Context Mode、Single Analysis Multi Output、120秒卖点覆盖策略必须同时存在且无旧版强制Python/JSON/Gate残留。
