# Long Context Mode｜AI-First 长文本模式

## 目标与边界

在数百到数千条字幕、数十分钟到数小时的直播文本中，保证输入和目标商品窗口不被截断或漏读。长文本模式管理读取覆盖和商品边界；商品理解、购买价值判断、去重、开头竞争和编排仍由 AI 在同一次语义处理中完成。

## 启用与读取

- 全文一次读取有明显截断、遗漏、上下文污染或商品反复切换风险时启用；约 1000 条以上是强信号而非硬阈值，2000 条、接近两小时的素材直接启用。
- 覆盖首尾、窗口之间的必要上下文以及目标商品全部离散片段。分段只管理输入范围；窗口地图只确认商品窗口，不成为卖点台账。
- 逐个目标窗口阅读时记录范围并理解归属、条件和合规边界；在全部目标窗口读完后，再一次性识别有效独立购买信息并控制粒度。不得每读完一段就锁定主线、生成候选或围绕局部方案补充卖点。
- 全量识别完成后，才生成候选购买路径；每个候选独立重新评估并完整编排全部有效卖点，按覆盖资格和完整方案标准比较。窗口地图只确认读取范围，不成为卖点台账。
- 用户未指定视频数量时，若存在多条差异化候选且每条都完整覆盖全量卖点，先建议数量与主题并等待用户选择后再生成多条；用户未选择时按单条默认完成。

## 前后位置公平

所有已读窗口中的候选都按 Universal Core 的同一标准进入比较。**前后位置公平**意味着：后段出现的强结果、重要顾虑回应或独立高决策价值亮点，必须与前段候选公平竞争；不得因为前面先出现了一个可用开头、先完成了局部方案、先读到一个强卖点或文本太长，就降低后段候选的竞争机会。

对前段与后段使用同一组语义标准：陌生顾客首屏价值、具体可信、可承接兑现、购买决策价值及商品归属。这个要求是全局读取覆盖与同次语义判断的结果，不是新增第二轮筛选、漏检流程、模型轮次或覆盖表。

## 装配与降级

1. 确认全文读取范围和目标商品窗口；只对确实缺失的范围补读，确保所有目标窗口完整读完。
2. 读完全部窗口后，按 `references/editorial-policy.md` 识别有效独立购买信息、控制粒度，再生成候选购买路径和完整编排；按 `references/highlight-selection.md` 区分有效卖点、证据、例子、递进和弱增量。
3. 依据单条或每条多视频的硬覆盖门槛筛选，再比较完整候选路径；如用户尚未选择多视频建议，先停在建议阶段。最后仅对获选方案按 `references/final-check.md` 完成一次终检，不另加独立遗漏扫描。

分段读取、时间码定位和时长累计可作为可选机械辅助；工具不可用时，只要文本仍可可靠读取就继续。只有文本无法取得、范围存在无法补齐的缺口或关键来源无法确认时，才说明受限。
