# C2 Universal 0.4.6｜购买信息覆盖、候选比较与时长

本文件是 Universal Core 中购买理由价值层级、覆盖要求、信息密度、时长压力处理、单条与多条规则的唯一权威。候选生成与完整方案排序见 references/editorial-policy.md；事实与归属边界见 references/global-rules.md 及适用的商品知识包。全部判断在现有一次分析和一次终检中完成，不另加模型轮次或日常流程节点。

## 购买决策价值层级

按当前商品、目标顾客和具体素材动态判断，不把某种类别固定成某一等级：

- **高决策价值**：明显影响顾客是否购买或能否判断适不适合，例如核心使用/穿着结果、关键顾虑的有效回应、重要适配条件、主要功能/体验，或原话清楚建立的首要购买理由。
- **中决策价值**：补充选择信息、加强可信度、说明使用/搭配/场景，或让已有理由更具体，但单独对购买与否的影响较弱。
- **低决策价值但有效的卖点**：确实提供新的商品事实、选择信息、使用/适配帮助或顾客可用信息，但对当前角度的购买决定影响较弱。它仍是有效独立购买信息，必须覆盖；只可少展开、后置或选更简洁的原话。
- **弱增量**：不是新的独立购买信息，且相对已经覆盖的内容没有新增信息或明确说服作用，例如同事实无增量近义复述、已被更强信息充分覆盖且没有新增说服作用的同一事实表达、泛夸赞、普通过渡或弱行动催促。只有识别为弱增量且其重复四步判断已完成，才可在压缩时删除。

**低决策价值≠弱增量。** 低价值但有效卖点必须保留。是否有效独立与价值高低是两个判断：有效性决定是否必须覆盖；价值高低只决定排序、展开篇幅、承接位置和表达选择。不能因低价值、非核心、主题关系弱、不容易衔接、长度已够或对当前角度价值低而删除已确认有效卖点。等级不按“材质/搭配/尺码”等品类名称固定；同一卖点在不同成片中可以有不同价值等级，每条候选须逐条复评，不得沿用另一条成片的价值排序。

## 重复表达：信息增量、说服增量与机会成本

对疑似重复的片段，在现有一次语义分析中按唯一顺序判断，不跳步：**先判同事实→判新增信息→判说服增量→最后取舍**。只有前一步成立后才进入下一步；不把同一主题、词面相似或句式相近直接当成重复。

在上述顺序中同时判断两类增量：

1. **信息增量**：是否加入新的理由、解释、证据、体验、条件、程度、场景或适配/选择帮助。
2. **说服增量**：即使事实相同，重述是否能在当前语境中明显加强顾客对核心利益的记忆、可信感、情绪感染或行动确定感。

据此区分并处理：

| 类型 | 识别要点 | 默认处理 |
|---|---|---|
| 机械性重复 | 口误、卡顿、半句重启、未完成句被完整句重说，未增加信息或说服作用 | 删除机械片段，保留完整、自然的表达；若仅前段无效，不能连完整句一起删。 |
| 强调性重复 | 同事实且没有新增信息，但重述有可感知的记忆/感染/说服作用 | 允许保留为有效强调；必须确认不是单纯换词，并且没有挤占更重要的独立购买理由或拖慢节奏。 |
| 递进性重复 | 后句带来原因、证据、体验、条件、程度边界或选择帮助 | 优先保留其新增部分；它不是纯重复。 |
| 过度性重复 | 同一事实已充分表达，后续没有明显新增信息或说服作用 | 默认压缩到最有力、完整、自然的一处；不得为增加时长而保留。 |

先判同事实不等于必删：有新增原因、证据、体验、条件、程度边界或选择帮助的递进必须保留；没有新增信息但有明确说服增量的有效强调可以保留。只有两类增量都没有时，才在最后取舍阶段默认压缩同事实的无增量近义复述。不得按词面相似度、固定重复次数或“一条字幕只留一次”规则机械删除。判断单位是当前语境中的完整表达及其顾客决策作用，而不是相同字词；一个词面不同的句子也可能没有任何增量。

**机会成本检查：**有效强调的保留价值须与它占用的时长、注意力及可能挤掉的独立购买理由比较。强调有助于记住主利益，却不能因此吞掉尺码适配、顾虑回应或其他会改变购买决定的独立理由。一般时长建议下限不能成为保留机械/过度重复的理由。

## 卖点覆盖与证据选择

- 覆盖对象是完整目标商品窗口中识别出的全部有效独立购买信息。每个候选都按其核心角度逐项判断每个卖点对本条角度的作用、重新评估完整集合；不得沿用别条方案的排序或因主题不同跳过。
- **单条正式方案必须覆盖全部已确认有效独立卖点**，并保留成立所需的必要证据和条件。可选最有说服力、最完整的一组表达，不要求保留同一卖点的所有重复证明、全部举例或所有字幕。覆盖门槛不通过的单条候选不能靠开头、连贯度或其他分数弥补；不能因低价值漏点。
- **每条多视频方案也都必须覆盖同一完整卖点池**，并独立组织全部有效信息与必要支持；不把信息分配到不同视频，不以某条主题或主线为由遗漏。方案并集覆盖全部有效卖点是额外一致性检查，不能代替逐条完整覆盖。
- **证据覆盖不等于卖点覆盖**：同一理由有多组支持时，可选足以成立的最好表达；新增原因、证据、体验、场景、限制或选择帮助若构成新的购买信息或必要条件，仍须覆盖。
- 每项字幕的工作可以是提出独立理由、证明已有理由、回应顾虑、帮助适配/选择、降低决策阻力或必要承接。泛夸赞和普通过渡没有新增作用时可压缩；但低决策价值的独立事实仍须占有承载位置。
- 完整购买理由仍须让顾客理解具体结果/用途/待解决问题，并保留必要依据和条件；孤立属性、泛夸赞或行动口号不能单独触发成交。单位时间购买决策价值与信息密度用于排序、篇幅和表达选择，不把已确认有效信息变成可删除项。

## 候选资格门槛、完整方案评分与选择

- 候选资格先于评分。候选须有明确顾客问题/结果、足够且归属清楚的原话证据、完整购买逻辑、全部有效独立卖点的完整编排，以及没有事实/商品归属硬伤；仅凭一句强钩子不够。
- 评分对象是完整候选成片。通过资格后，对顾客问题强度、首屏停留价值、核心理由完整度、全卖点承载自然度、叙事连贯度、购买决策效率六项进行相对评分和排序；不对单个卖点评分，不设固定卖点权重、固定维度权重或必须展示的数值总分。
- 单条默认取综合第一。多条第一条取综合第一；后续从同一候选池中结合候选自身质量、与已选方案的实质差异和完整路径区分度选择，禁止机械 Top N 或同质候选仅换开头。
- 同分或接近时依次看顾客问题强度、证据完整性、全卖点承载自然度、连贯性、信息密度、剪辑可执行性。剪辑可执行性只作为文本条件下的次级排序因素；不能据文本推断画面，也不作硬性否决。
- 候选池和评分是 AI 内部比较过程。日常交付不增加评分表、固定类目模板、卖点权重表、JSON 台账或第六部分。

## 多条方案：同一候选池、逐条完整覆盖与用户选择

- 明确要求多条时，每条都交付完整、可独立成立的方案，最多三条；每条须有明确的核心购买角度，并通过同一候选池形成差异化组合。第一条固定取候选池综合第一；后续在高分候选中按自身质量及与已选方案的实质差异选择，不机械取排行榜前 N 条。
- 实质差异须体现在核心顾客问题、购买理由或叙事路径，不得只更换开头、结尾或 CTA。多条共享必要核心理由可以，但不能掩盖路径同质。
- 每条方案必须各自覆盖全部有效独立卖点并保留必要证据和条件；并集覆盖全量仅作额外检查，不能弥补任何一条的遗漏。
- 没有足够差异化候选时不为凑数量降质。未指定条数时，若存在多条实质差异化候选且每条都能完整覆盖全量，应先建议视频数量与主题，说明每条均全量覆盖，并等待用户选择数量及主题后再正式生成。用户未选择时不输出多条正式成片，可按单条默认完成。
- 多条不由时长触发。不得把 120 秒作为删减或拆条门槛；一条自然连贯且覆盖全部有效卖点时可交付单条。

## 时长下限与动态取舍

- 以 1.2 倍速估算时，**45 秒是一般成片的合理下限参考**，不是硬性拒绝门槛。成片长度由购买理由是否讲清、重要信息是否需要、节奏是否自然和单位时间价值决定；**不设固定时长上限，取消 120 秒硬上限，时长不作为任务完成条件**。
- 若素材完整且有价值的购买信息需要更长时间，超过 120 秒本身不是删减或拆条理由；只在低增量、重复或节奏拖沓时压缩。不得为达到某个时长、覆盖更多字幕或证明规则而灌水。
- 充分筛选后低于 45 秒，先在同一次分析中确认没有遗漏可自然加入的重要理由或必要条件。对耳饰、饰品等本身可用讲解较短的类目，或实际有效素材确实较短的商品，可在**成片质量合格**时按“短时长例外”交付：至少有陌生顾客可理解的核心购买理由及其所需证据/条件，来源和商品归属清楚，表达连贯、不误导，不靠机械/过度重复补时长；原话存在自然购买机会时保留，不能补造 CTA。类目名称本身不自动豁免质量要求。
- 低于 45 秒且理由仍不完整、重要顾虑未交代、归属/证据不清或连贯性不合格时，标为“短候选，非正式成片”，说明缺口并建议补充同商品素材；不得把不合格内容包装为短时长例外。
- 时长估算：选段原始时长除以 1.2，再加已知未加速片头/转场/停顿；SRT 按连续组起止跨度估算并计入组内空隙，逐条时长文本累计入选条目。来源时间码保留原素材 1.0 倍口径。毫秒四舍五入到最近 1 毫秒，正好半毫秒向上。
- 若长度影响注意力或节奏，按以下优先顺序压缩：**机械性重复 → 过度性重复 → 弱增量 → 泛夸赞 → 普通过渡 → 弱 CTA → 同一卖点的过多证明**。必要时压缩表达、选择代表性例子或减少非必要承接，但不得删除有效独立卖点。覆盖及必要证据/条件未达标时，不得以时长压力结束或删点；不得因超过120秒删掉重要理由。
- 时长是质量说明，不是覆盖率或视频长度目标。时长压力不得删除有效独立卖点。若成片很长，检查是否确有值得保留的独立理由、必要证明和顾客决策价值；如无新增价值，按机会成本压缩。若成片较短但购买理由完整且适合短素材例外，不为时长补入弱内容。

## 停止条件

只有在全部有效独立卖点已有承载表达、必要证据和条件已经完整，且剩余素材仅为重复、弱增量、动态交易信息、其他商品内容或事实/合规不合格内容时，才可停止编排。单条和每条多视频方案都分别核对全量覆盖；方案并集只作额外一致性检查。核心角度、时长、主题衔接或已完成一个强主线，均不构成停止条件。
