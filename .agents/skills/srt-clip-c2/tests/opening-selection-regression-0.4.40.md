# C2 Universal 0.4.40｜开头候选与成片映射回归

本表是当前有效测试资料，不记录已废弃的历史业务规则。候选展示不限量；用户可从完整候选中选择至多三个开头，选择数量决定独立成片数量。每条成片必须从对应的用户所选原话开始，并独立动态编排、覆盖完整有效信息池。

## 固定测试矩阵

| 场景 | 输入/操作 | 通过条件 |
| --- | --- | --- |
| 超过三个合格候选 | 目标商品信息池中存在 5 个以上实质不同且达标的候选 | 全部合格候选均展示；顺序按来源或可读性稳定呈现；四项字段齐全；不预选、不代选、不凑数 |
| 候选数量小于或等于三个 | 0、1、2、3 个达标候选 | 展示数量与合格候选数量相同；不为凑数降低门槛 |
| 用户未选择 | 展示候选后用户尚未选择 | 保持等待，暂停生成成片 |
| 用户选择一至三个 | 选择 1、2 或 3 个候选 | 分别生成同数量的独立完整成片 |
| 用户选择超过三个 | 一次选择超过 3 个候选 | 阻断成片生成，提示用户从已展示候选中重选至多 3 个；不得静默截断 |
| 开头与成片对应 | 选择多个不同候选 | 每条成片必须以对应用户所选开头原话开始；不得由其他候选替换、合并或顶替 |
| 主体动态编排 | 选择的开头及购买核心不同 | 各条独立动态划分、判断并排序内容板块，完成动态板块编排；主体可合理复用，结构不得机械复制或为差异强行改坏 |
| 完整覆盖与超长 | 每条独立核对全部有效卖点和必要支持 | 正常时长逐条覆盖完整有效卖点；超长时逐条按现行超长例外处理，说明被省略的有效信息及原因 |
| 来源与交付 | 输出多条完整成片 | 原话、序号、商品归属、合规及必要语境逐条核对；按固定五部分交付；第五部分序号逐条对应成片正文 |

- 测试选择是回归输入，不代表用户已实际选定：选 `135–137`、`652–655`、`802–805`，生成 3 条独立成片。每条 81–82 个字幕片段、预计 83–84 秒；逐条覆盖 13 个有效信息组及必要证据/条件，开头原话准确置首，逐字映射与第五部分序号均 PASS。三条分别动态调整板块顺序，且没有把其他候选开头带入正文。
- 空选择为 `AWAITING_USER_CHOICE`，生成 0 条；模拟选择 4 个为 `BLOCKED`，生成 0 条且不静默截断。
- 三条均未达到超长触发条件，因此本次真实素材没有触发超长例外；未将正常时长样本伪称为超长验证。现行超长处理边界由规则一致性与发布门禁另行核验。
- 全源正式禁词直接命中为 0；选段排除直播间价格、限时、库存及催促交易话术。售后、正品等需额外核实的说法未混入成片。
- 五部分交付顺序、三条完整正文、每条一个标题及五个话题、第五部分序号对应最终正文均 PASS。
- 质量边界：候选资格、卖点语义、商品归属、动态交易信息及板块质量由完整素材语义审阅判断；脚本只核验记录完整、原话/序号/时长映射、禁词命中、覆盖引用和输出结构。
