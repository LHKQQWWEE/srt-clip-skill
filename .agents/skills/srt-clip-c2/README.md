# SRT Clip C2 Universal 0.3.19

AI 主导的跨平台带货视频文本剪辑 Skill。正式支持 SRT 与逐条时长文本，通用核心与类目专项模块分离。

## 核心特征
- 四个固定触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。
- 不使用通用触发词 `切片文案`。
- 默认不调用 Python，不创建强制 JSON 台账，不执行多轮工作流门槛。
- 自动识别商品类别并加载已建立的专项模块。
- 1.2倍速预计成片时长不超过120秒。
- 保留原话、原始序号、商品归属和不同购买信息覆盖。
- 固定五部分输出。
- 全局禁词只通过用户审核截图或明确指定词句更新；所有类目继承，命中整条字幕序号排除，日常离线执行。
- 开头默认从第一次刷到视频的陌生顾客停留价值出发；不设固定钩子类型排序，颜色/搭配等按实际顾客收益竞争而非关键词封禁。
- 成交按顾客决策推进价值判断；限定老粉/老顾客话术默认降级，弱成交不得挤占独立有效卖点。
- 亮点覆盖执行“单条最优、多条互补”：单条不为覆盖率硬塞低价值内容；多条允许核心购买理由共享、次要有效理由按决策价值互补，每增加一条都应产生新增购买决策价值。用户明确要求2—3条时以请求数量为目标，素材不足时只交付可成立的高质量方案并说明，不为凑数补弱内容。

## 唯一规则入口
从 `SKILL.md` 开始；详细规则按需读取 `references/` 和 `categories/`。本 README 不另设业务规则。

- Long Context Mode：长文本按商品窗口保证读取范围；购买信息筛选与编排在同次 AI 语义处理中完成，不增加卖点池、遗漏检查或模型轮次。
- AI-First Constitution：所有语义决策必须由AI完成，工具只能辅助机械读取/定位/计算。
- 版本治理：未来升级遵守 `references/update-protocol.md` 的六项审查与三条一票否决（仅针对开发/发布，不增加日常执行负担）。
