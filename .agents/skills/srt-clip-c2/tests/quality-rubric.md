# C2 Universal 0.3.0｜质量验收标准

## 硬性门槛（任一实质失败即不通过）

- 原话被擅自改写、补造或拼接。
- 商品归属串用，或不同款式的事实混用。
- 伪造字幕编号、来源或时间。
- 单条方案1.2倍速预计时长超过120秒。
- 全局禁用词句被错误保留，或禁用范围被擅自扩大。
- 误把缺少证明说成已知虚假，或虚称平台已拒审。
- 声称运行了实际未运行的程序、完整读取了未读取的文件或核验了未读取的视频。
- 固定五部分输出结构实质缺失。

## 质量评分（100分）

| 指标 | 权重 |
|---|---:|
| 商品识别与窗口归属 | 15 |
| 亮点完整性与去重 | 20 |
| 开头吸引力 | 10 |
| 原话与序号准确性 | 15 |
| 时长计算与限制 | 10 |
| 衔接与成交逻辑 | 15 |
| 合规风险判断 | 10 |
| 输出格式 | 5 |
| **总分** | **100** |

建议通过线：90分，且全部硬性门槛通过。平均分不能抵消硬性错误。

## 测试报告必须区分

- 规则/结构静态检查。
- 当前 AI 对历史样本的实际语义测试。
- 不同 AI 平台的独立兼容测试。
- 程序实际执行测试。

未实际运行的类别标记“未测试”，不得推断跨模型兼容已经通过。
