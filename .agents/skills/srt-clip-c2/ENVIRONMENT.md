# C2 Universal 0.4.3｜运行环境

- 普通任务不要求 Python、第三方依赖、联网或远程服务。
- SRT 和逐条时长文本由当前 AI 宿主读取；复杂计算、分段定位或来源核验确有必要时，宿主工具可作为可选机械辅助。
- 总决策、动态结构、事实边界、原话剪辑与终检由一个 AI 承担，不创建额外 Agent 或分析轮次。
- 所有语义判断由 AI 完成；工具不可用时，只要文本仍可可靠读取就继续执行。
- 不包含 MP4 解码、ASR 或音画核验能力；未实际查看的视频、商品资料或剪辑导出不能声称已核实。
- 测试脚本只用于开发/发行验收，不在日常任务中运行。
- Long Context Mode 不要求 Python；长文本通过可用读取能力保证窗口覆盖，购买判断仍按 Universal Core 完成。
- 商品知识包仅提供事实边界，不规定内容结构。
- 注意力衰减、低完播截断压力测试和购买机会前移都属于现有一次分析/一次终检；不增加固定时间点、Agent、工具或语义轮次。
- 版本治理按 references/update-protocol.md 执行，不增加普通任务前置步骤。
