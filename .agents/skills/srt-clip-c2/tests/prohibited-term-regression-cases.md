# C2 Universal｜违禁词管理与精确范围真实文本回归案例

这些案例按当前 C2 Universal Core 0.4.7 / Skill 0.4.49 正式规则复核，用于开发测试中验证直接命中、已确认等价表达、字段范围、绝对化语境边界、标准化、精确字幕范围和疑似风险分离。词条、触发条件与例外均以 `references/global-rules.md` 唯一词库为准；脚本只测试登记的明确边界，日常剪辑不调用脚本，完整商品归属和语境仍由 AI 判断。

| 3 | “这件不是全羊毛，是棉涤混纺。” | 正式词直接命中，整条字幕排除；不将剩余片段改写保留。 | 通过：整条字幕命中 `羊毛`。 |

| 8 | “亮片是织进纱线里面的，不是用胶粘上去的。” | 按工艺事实及否定语境理解；有依据时保留，不误判成“不会掉”承诺。 | 通过 |
| 9 | “用户提供审核截图，截图明确把‘绝对安全’标为违规表达。” | 允许按截图可定位范围更新正式库；只纳入被标出的表达及真正等价项，不扩展为所有绝对词。 | 通过 |
| 10 | 促单句：“点击商品卡下单，这款全网最好。” | `全网最好`在商品宣传语境触发绝对化拦截；促单不豁免，只排除完整命中字幕句。 | 通过：扫描器分类为商品绝对化命中，最终成片 gate 失败。 |
| 11 | “AI从一份政策简报推测‘最安全’可能有风险，准备自行加入违禁词库。” | 拒绝新增；可在相关语境中作风险提示。 | 通过 |
| 12 | “政策简报建议谨慎使用某个尚未登记的表达。” | 简报只用于风险提示，不自动改写正式词库；不得据此补入词条或近义表达。 | 通过 |

上述 1–12 项按当前词库与语境规则复核；明确列出的商品宣传结构拦截，普通语言放行，未入库表达和语境不明表达只提示。机械脚本不能替代完整商品归属、事实或语义审查。
