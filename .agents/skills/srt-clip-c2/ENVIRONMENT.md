# C2 Universal 0.4.6｜运行环境

- 普通任务不要求 Python、第三方依赖、联网或远程服务。
- SRT 和逐条时长文本由当前 AI 宿主读取；工具只作可选机械辅助。
- 总决策、动态结构、事实边界、原话剪辑与终检由一个 AI 在一次语义分析和现有一次终检中完成。
- 长文本先覆盖所有目标窗口，再识别全量卖点并比较候选；单条及每条多视频均须完整覆盖全部有效卖点。
- CTA 是可选项，不强制提前安排，也不成为任何时长或覆盖门槛。
- 用户未指定数量时，多个主题都可行且每条均能全量覆盖的，先建议并等待选择后再生成多条。
- `scripts/prohibited_term_guard.py` 是可选字面扫描器，不是日常工作门槛，也不执行语义等价、事实或覆盖判断。
- 时长不作为任务完成条件；保留 45 秒一般下限参考、短时长质量例外和无固定上限。
- 不包含 MP4 解码、ASR 或音画核验能力；未实际查看的视频、商品资料或剪辑导出不能声称已核实。
