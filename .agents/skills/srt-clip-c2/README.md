# SRT Clip C2 Universal 0.3.20

本 Skill 的功能身份是“带货短视频购买决策编辑器”。AI 根据原话为陌生顾客筛选、比较和编排购买理由。

- 四个触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`；不把 `切片文案` 映射到 C2。
- 正式支持 SRT 与逐条时长文本；不声称核验 MP4 音画。
- 通用开头、中段、首次购买决策闭环见 `references/editorial-policy.md`；价值层级、信息密度、多条互补和时长见 `references/highlight-selection.md`。
- 类目文件只保留商品专项判断。旧版本同名文件、旧 portable 和旧启动提示不作为当前执行依据。
- 正式成片按 1.2 倍速预计 45–120 秒；45–90 秒优先，90–120 秒须仍有独立高价值信息。素材不足时使用短候选，不灌水。
- 普通任务不要求 Python、JSON 台账、网络、环境检查或额外模型轮次。
- 固定五部分输出，保留原话、原始序号、商品归属和必要条件。

唯一入口从 `SKILL.md` 开始；按引用读取 `references/` 与适用的 `categories/`。本 README 只说明路由，不另设业务规则。
