# Changelog

## 0.3.20 (2026-11-17)

- Defined the single functional identity as a short-video purchase decision editor and made Universal Core the authority for general structure.
- Replaced opening selection with the unfamiliar-customer first-screen value test and explicit strong-versus-weak candidate competition.
- Defined the first purchase decision closure around a formed purchase reason and a natural, lower-resistance opportunity; selection continues after the first close.
- Added dynamic high/medium/weak decision-value tiers, a no-omission-without-reason rule for independent high-value points, unit-time decision value, and decision-chain structure.
- Set formal duration to 45–120 seconds at 1.2x; 45–90 seconds is preferred, 90–120 seconds requires further independent high-value content, and filler is prohibited.
- Added fair competition for later strong points in long text, complementary purchase paths for multiple cuts, concise Part 3 reason summaries, explicit final-check failures, and revised quality weights.
- Consolidated common structure into Universal Core; category files retain product-specific judgments. No daily Python, JSON, network, environment gate, or extra model round was added.
- Updated active entry points and the portable package. External GitHub/plugin/Drive publication is recorded separately in the release acceptance record.

## 0.3.19 (2026-11-17)

- Removed the historical sample index from the active skill and distribution because it could still be read as prior task context.
- Kept only the current release acceptance record; superseded acceptance, regression, archive, and release-note files were excluded from that distribution.
