# 一次最终检查清单

每条正式交付在输出前完成现有的一次整体检查。此检查核实成片，不新增独立卖点遗漏扫描或全文复查阶段。

1. **输入范围**：确认实际读取的 SRT/逐条时长文本范围；未读或截断范围不能假称已读。Long Context Mode 使用窗口地图确认目标范围完整。
2. **商品归属**：每条入选原话确实属于目标商品；不同商品、不同款式的规格没有混用。
3. **类目规则**：已识别商品类别并加载已存在的适用模块；没有专项模块时没有借用其他类别规则。
4. **原话来源**：每条入选字幕原话、原始序号和来源位置一致；没有改写、补造或伪造编号。
5. **购买信息与去重**：入选片段各自提供有效信息，或属于同一卖点的有价值补充；同类别不同事实未被当成重复。检查实际取舍是否符合语义去重和价值优先级；这不是回扫原文的另一个筛选阶段。
6. **结构与衔接**：开头符合现行规则，中段可同时承载多个类型的有效信息并自然推进；如使用反差，它必须有原文支持。结尾自然；重排后对象、条件和原意正确。
7. **时长**：按现行 1.2 倍速规则计算，每版不超过 120 秒。接近上限时，裁剪遵循 highlight-selection.md 的优先级，独立有效卖点只在确实时长不足时才考虑舍弃。
8. **合规**：目标商品素材按现行规则筛查全局禁令、材质/功效证据和动态信息；完整原始序号排除边界正确，未虚称平台审核结论。
9. **标题与话题**：一个标题、五个与当前类目相关的话题；不得混入未加载类目的固定话题，遵守全局标题/话题禁令。
10. **多方案一致性**：需要多方案时，方案来自同一次商品归属、购买信息判断和合规结论；不因侧重点差异删除独立高价值信息。
11. **AI-First 与效率**：AI仍拥有所有语义决策权；普通任务没有新增脚本、结构化台账、模型轮次或额外确认门槛。
12. **五部分输出**：顺序、来源序号代码框、方案行数和必要风险说明均正确。

## 错误处理

- 发现错误只修复对应部分，并重查受影响项目。
- 无法确认商品归属、输入范围或关键时长时，说明限制，不猜测。
- 未调用程序时，报告“模型逐条对照，未运行程序”；不得使用“程序通过”“来源核对PASS”等表述。
- 本清单不构成程序证明，也不保证平台审核结果。
