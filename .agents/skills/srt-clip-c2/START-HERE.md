# SRT Clip C2 Universal 0.4.4｜开始使用

当前唯一执行版本为 **0.4.4**。只使用本目录的 SKILL.md 与其明确引用的当前文件；不从历史副本、旧 portable 或缓存内容加载规则。

## 支持范围

- SRT 文件
- 逐条时长文本

MP4 不属于正式跨平台范围。SRT 与 MP4 同时提供时只按文本剪辑，不声称核验画面或原声；只有 MP4 时，请用户提供文本。

## 四个触发词

srt文案、srt切片文案、str文案、C2完整精简版。通用词“切片文案”不是 C2 触发词。

## 执行原则

一个 AI 在一次语义分析中承担总决策、动态购买决策架构、事实边界和原话编排等逻辑职责，再做现有的一次终检。各职责不是额外 Agent 或串行模型。内容结构按商品、顾客、证据和实际购买理由动态选择；商品知识包只提示事实、条件与归属边界，不提供模板。

先完整识别目标商品的有效卖点，再为每条成片确定自己的核心购买角度，并按该角度重新评估全部卖点。单条尽可能完整覆盖；多条差异化组合并尽可能整体覆盖。购买推动是可选项，不按开头、截断位置或时长强制提前。

对重复表达判断信息增量、说服增量及机会成本：删除机械重启，允许有记忆/感染收益的强调，保留增加原因/证据/体验/条件的递进，压缩没有明显增量的过度重复。不得用相似度或固定次数机械删减，也不得让强调挤占更重要独立理由。

按1.2倍速估算时，45秒是一般合理下限参考，没有固定时长上限；取消120秒硬上限。用户要求多条时，每条都交付完整方案；未指定条数时，根据差异化角度和整体卖点覆盖决定给一条或多条完整方案。保留原话、来源、商品归属和必要条件；固定五部分输出。

正式禁词只排除实际命中的完整字幕序号，不连带邻近字幕；相似字词和风险提示不能扩大命中或触发整段淘汰。保留的行动句仍须有完整原话和本地语境。动态价格、优惠、库存、限时、直播专属福利、涨价和稀缺等默认排除。
