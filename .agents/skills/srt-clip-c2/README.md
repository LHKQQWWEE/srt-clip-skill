# SRT Clip C2 Universal 0.4.6

插件包版本：**0.4.23**；业务内核：**0.4.6**。入口按 runtime manifest 加载当前引用；可选工具支持预处理、原话组装及机械终检。

一个 AI 在一次语义分析中通过现有职责完成带货短视频购买决策剪辑。先完整读取目标商品上下文、识别全部有效独立购买信息并控制粒度，再比较完整候选路径。

- 单条和每条多视频方案都须覆盖全部有效独立卖点及必要证据/条件；方案并集只作额外一致性检查。
- 开头在目标商品全文跨主题比较；问题钩子与必要回应一起评估，具体数字和主播经历不自动优先。
- 用户未指定数量时，先推荐可成立的多视频数量与主题，并等待用户选择后再正式生成多条方案。
- 直接禁词按唯一词库扫描，只排除实际命中的完整字幕。`羊毛`为正式禁词；`羊绒`单独出现也命中正式禁词；防静电和相邻字幕不连带命中。
- 时长不作为任务完成条件；45 秒一般下限参考、短时长质量例外和无固定上限均保留。
- 可选脚本只做字面直接匹配，不取代 AI 的语义、商品事实或卖点覆盖判断。
- 可选 `scripts/srt_tools.py` 一次输出解析范围、时长/跨度、正式词库 HIT、窗口图支持数据和三列紧凑表；同一个 selection JSON 可组装正文、时长与第五部分序号并运行机械 gate。
- 机器 gate 只验结构和正式词库直接命中；卖点池、原话支撑、事实归属、必要条件、语义等价、跳点连续性与完整候选评分仍由 AI 判断。工具缺失时按“模型逐条对照”继续五部分交付。
- 候选对比保留完整路径、卖点 ID 到支撑序号映射、必要证据/条件、跳点核验和六维比较；只展开获选方案原文。

执行入口与完整规则见 [SKILL.md](SKILL.md)，便携版见 [C2-Universal-Portable.md](C2-Universal-Portable.md)。
