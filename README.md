# 直播切片文案 C2 0.2.5

现行规则在 [.agents/skills/srt-clip-c2/SKILL.md](.agents/skills/srt-clip-c2/SKILL.md)。按商品主线灵活选择原话，不固定卖点数量或70秒目标；统一预计1.2倍速45–90秒，保留来源及五部分交付。千川与抖音电商离线参考见技能内 references，用户要求更新时联网核对。

支持 SRT、逐条时长文本、MP4+SRT 和实际可读的 MP4-only；文本脚本不解码视频。安装后在技能目录运行 `python -S tests/test_portable.py` 验证。程序不证明语义、平台合规或音画。
