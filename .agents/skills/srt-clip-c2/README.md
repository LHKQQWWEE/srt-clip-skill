# SRT Clip C2 Universal 0.4.7

Skill 版本：**0.4.50**；业务内核：**0.4.7**。执行入口见 SKILL.md。本 Skill 也支持抖音电商增长咨询；区分已知事实、推断和待核实事项，提供优先建议、下一步和观察指标。重大工作流调整先提交方案并等确认。SRT 违禁词依唯一词库先扫原始字幕、逐句过滤、建信息池、编排、复扫并核序号；直接词条机械拦截，绝对化表达按登记的商品语境分类，明确商品宣传命中整句、正常语言放行、不确定与疑似 ASR 仅提示。“首选”不因个人意见或客观事实证明而获得商品宣传豁免。

- 一个 AI 在一次语义分析和现有一次终检中完成全部判断。
- 多商品先列商品及讲解窗口并等待用户选择；选择后完整读取所选商品并建立信息池。目标明确或仅一件商品时跳过商品选择。
- 钩子与必要紧邻承接联合评估，综合判断前 2 秒吸引力和前 5 秒连续吸引力；1.2 倍速对应原素材累计 2.4 秒/6 秒，仅作参考、不硬截原话。开放式观看动力优先级用于确定候选池；按实际观看动力动态分类，不按卖点类别或名称机械判断，第一优先级内部无固定顺序、权重或评分。
- 完整信息池后展示候选池内所有达到质量门槛且彼此实质不同的真实开头，不设数量上限；每个只含方案名称、开头原话、原始 SRT 序号和预估时长。不得遗漏合格候选、包装重复候选、预选、代选或凑数。用户最多选择三个，用户选择几个就分别生成几条独立成片；每条必须从对应用户所选开头开始，并独立动态编排、覆盖完整有效卖点池和必要支持。
- 每条成片先从完整信息池规划全部独立有效卖点及必要支持，写稿前完成时长预算、购买信息单元竞争与首次容量优化，首稿直接采用优化选段；相似主题不粗暴去重，保留有效候选删除依据并逐条独立复核覆盖。板块动态编排且不跨板块穿插。全片按 1.2 倍速估算（原始累计时长 ÷ 1.2），90 秒为目标、90–95 秒优先、95–100 秒复核、超过 100 秒专项优化并复核；120 秒原始时长对应 100 秒播放复核线，必要且不可替代内容可说明依据后超时，不自动截断。
- 重复话术在完整信息池后按购买信息单元竞争，不按主题粗暴去重；无新增购买信息的相近表达择优保留，独立事实、证据、体验、条件、场景和选择帮助分别核对。每个未入选的有效候选保留序号、信息单元、取舍理由和对应覆盖原话；每条成片独立复核信息覆盖。
- 促单独立识别且不计入卖点支持或价值排序；适用且合规原话完整置于最后板块，结尾动态交易信息无活动例外，促单绝对化用语照常审核。
- 最终终检只检查实际写出的成片；原话、字幕序号、商品归属、禁词边界、风险提示、CTA、固定五部分纯文本交付和 AI-First 边界保持不变，不引入画面辅助。
- 原始序号是硬验收红线：不可变序号/原话/时长映射、正文及第五部分序号必须逐项一致，否则不得交付。固定五部分交付、正式词库范围、原话和商品归属边界保持不变。

Python 工具仅供开发、构建与发布测试使用，不进入日常 SRT 执行。便携版由开发构建流程从当前权威规则生成。
