# 一次最终检查清单

每条正式交付在输出前完成一次整体检查。不要为此生成 JSON 台账或启动多轮程序工作流。

1. **输入完整**：确认实际读取的 SRT/逐条时长文本范围；有截断时补读，不能假称完整。
2. **商品归属**：每条入选原话确实属于目标商品；不同商品、不同款式的规格没有混用。
3. **类目规则**：已识别商品类别并加载已存在的适用模块；没有专项模块时没有借用其他类别规则。
4. **原话来源**：每条入选字幕原话、原始序号和来源位置一致；没有改写、补造或伪造编号。
5. **亮点完整性**：回看全部目标窗口，反向检查核心和不同次要亮点；同义合并确实表达同一具体信息。
6. **结构与衔接**：开头自足且有吸引力；中段有相关承接；结尾自然；重排后对象、条件和原意仍正确。
7. **时长**：按1.2倍速计算，计入已知未加速内容；每版不超过120秒；短候选标识正确。
8. **合规**：检查全局禁用词句、材质/功效/资质证据、价格库存和当前素材拒审反馈；区分缺少证明与已知不实。
9. **标题与话题**：一个标题、三个专属生成话题、两个固定话题；遵守“羽绒服”标题/话题禁用规则。
10. **五部分输出**：顺序、来源序号代码框、方案行数和必要风险说明均正确。

## 错误处理

- 发现错误只修复对应部分，并重新检查受影响项目。
- 无法确认商品归属、输入完整性或关键时长时，说明限制，不猜测。
- 未调用程序时，报告“模型逐条对照，未运行程序”；不得使用“程序通过”“来源核对PASS”等表述。
- 本清单是模型语义与来源复核标准，不是独立程序证明，也不保证平台审核结果。
