# SRT Clip C2 Universal 0.4.6｜开始使用

插件包版本：**0.4.23**；业务内核：**0.4.6**。入口按 runtime manifest 加载当前引用；可选工具支持预处理、原话组装及机械终检。

当前唯一执行版本为 **0.4.6**。从本目录的 [SKILL.md](SKILL.md) 进入；历史版本和验收记录不覆盖现行规则。职责是同一 AI 在一次语义分析中完成的逻辑职责，不是多 Agent 流程。

## 支持范围

- 触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。
- 输入：SRT 或逐条时长文本。只有视频文件时请提供文本；不声称核验未查看的画面或原声。
- 一个 AI 完成一次语义分析和现有一次终检；工具不是普通任务前置条件。

## 覆盖和方案

先完整读取目标商品上下文并识别全部有效独立购买信息。单条及每条多视频方案均须完整覆盖同一卖点池和必要支持，方案并集不能补足单条遗漏。未指定数量且存在多条可行差异化主题时，先建议数量和主题，等待用户选择后再生成多条。

开头从目标商品全文跨主题比较；数字和主播经历不自动优先。问题型入口要连同紧随其后的必要回应一起看，确认问题相关、回应对应并有原话兑现。

正式禁词唯一列表见 `references/global-rules.md`。`羊毛`无条件直接拦截；`羊绒`单独出现也命中正式禁词；防静电及邻近字幕不连带命中。可选扫描脚本不决定语义或事实。

时长不作为任务完成条件。保留 45 秒一般下限参考、短时长质量例外和无固定上限；CTA 可选。最终按固定五部分交付。
