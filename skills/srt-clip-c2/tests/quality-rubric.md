# C2 Universal Core 0.4.7｜Skill 0.4.51 质量验收

本标准用于开发和发布验收，不增加日常剪辑步骤。AI 仍是唯一语义判断者；日常执行不调用 Python、脚本或外部工具。

## 一票否决项

任一项实质失败即不通过：

- 商品识别、归属、重复语义、动态内容结构、原话边界、正式违禁词范围或 AI-First 单 AI 架构被破坏。
- 多商品任务未先呈现商品身份与原始讲解窗口并等待用户选择；未选商品前生成其开头候选或成片。
- 未完整读取所选商品的有效窗口、未建立完整有效信息池，就比较开头或生成成片。
- 遗漏任何达到现有质量门槛的开头候选、把实质相同的开头包装成多个候选、候选字段超出方案名称/开头原话/原始 SRT 序号/预估时长、预选/代选/凑数，或用户一次选择超过三个后仍直接生成成片。
- 未按用户选中的每个开头分别生成独立完整成片；每条成片未先独立覆盖完整有效卖点及必要证据、条件与限制，再逐条执行容量复核，或用其他成片补足本条。
- 用完整成片竞争、资格打分或多维排名取代开头候选比较；存在合格观看动力驱动型钩子却越级选其他类型；没有合格第一优先级候选时未回退到其他有效钩子；按卖点类别或类型名称机械归类；把主播设问误写成真实顾客反馈。
- 未全量识别和覆盖有效购买信息及必要支持；超过 100 秒未逐条复核，自动截断，或省略低价值内容时拆散板块、损害必要理由、证据、条件与衔接。
- 原话、字幕序号、时长、商品归属、条件或播放顺序错配；不可变原始映射与成片正文/第五部分序号不一致或无法核实。
- 促单与卖点支持或价值排序混用；适用且合规的促单没有以完整原话置于末板块；结尾促单保留实时交易信息或豁免绝对化审核。
- 正式禁词范围被扩大；风险提示被当成机器硬失败或合规结论；全片估时没有按原始选段累计时长 ÷ 1.2 折算，或把 90 秒目标、100 秒参考当成自动截断线。
- 固定五部分交付缺项；新增模型、Agent、额外语义轮次或普通文本任务环境硬依赖。
- 声称运行了未执行的测试、读取了未读材料、审阅了未查看的音画或同步了无法读回核实的渠道。

## 开发质量评分（100 分）

此评分只评估 Skill 的开发质量，不用于比较日常成片或卖点价值。任一一票否决项失败时，不得以评分抵消。

| 指标 | 权重 |
|---|---:|
| 单 AI 决策边界、业务规则冻结及商品顺序选择 | 18 |
| 完整读取、信息池、文本上下文及事件连续性 | 18 |
| 动态开头判断与四字段候选选择流程 | 15 |
| 每个已选开头独立成片及逐条覆盖 | 16 |
| 原话、归属、合规与促单边界 | 12 |
| 不可变序号/原话/时长映射及最终序号硬门 | 12 |
| 时长、逐条容量复核与固定五部分 | 9 |
| **总分** | **100** |

建议通过线：90 分，且全部一票否决项通过。真实素材语义和音画效果仅在实际取得并核验对应材料后报告；缺失材料须标 BLOCKED/未验证。
