## 通用合成策略场景与预期判定

以下短文本为规则桌面回归，不是用户字幕。验收重点是信息判断和编排原则，不要求工具输出结构化卖点池。

| 场景 | 合成原话要点 | 预期判定 |
|---|---|---|
| 多卖点服装 | “肩线往里收不显肩宽；腰线做高更显腿长；面料贴肤不扎；冬天可以叠穿” | 四项分别有购买信息；按自然承接排序，不因类别不同删项 |
| 同类别不同信息 | “前掌空间宽不挤脚；鞋底软；跟高三厘米；配直筒裤显利落” | 鞋类四个事实分别判断，不把“脚感/鞋型”当同义 |
| 大量重复表达 | “特别显瘦；真的很显瘦；穿起来非常显瘦” | 无新增信息的重复夸赞择优留一处 |
| 真实冲突/反差 | “担心小个子压身高；高腰线配短上衣更显腿长” | 可把顾虑与原文回应相邻，轻量提高承接优先级，不扩大为保证 |
| 无冲突/反差 | “颜色柔和；面料有垂感；适合通勤” | 直接按购买价值编排，不补造问题或故事 |
| 陌生顾客钩子竞争 | “四个颜色都好看；整体小巧精致不肥大；丰满身材更适合软垂纱线” | 不按类型固定排序；纯颜色默认降级，优先比较顾客结果、相关性、差异性和承接，差异性不作硬门槛 |
| 限定老粉成交 | “老粉推荐两个颜色；普通顾客可按需求选基础色” | 老粉限定话术默认降级，不把陌生用户排除在首要成交节点之外 |
| 超时多卖点 | 独立版型、材质、舒适度、搭配、场景、限制均超过时长容纳 | 先去重、删无新增夸赞与弱/重复成交，再删低价值和已覆盖次级信息；独立信息最后才舍弃 |
| 短文本 | 一句完整的商品效果与真实收尾，约20秒 | 保持短候选标记，不为凑时长添加内容 |
| 长文本 | 多商品交替、目标商品多次回场，后段新增护理限制 | 先保证窗口覆盖；目标窗口内一次语义处理，保留后段新信息及条件 |
| 多商品 | 外套与围巾交替讲解，用户指定围巾 | 只编排围巾购买信息；外套独立规格不混入 |
| 非服装类 | 首饰：不掉色体验、耳针材质、过敏限制、礼赠场景 | 各信息按增量处理；不套用服装版型规则 |
| 类目专项 | 鞋：脚背条件/鞋底设计；围巾：肤感/护理；服装：版型/叠穿 | 各类目特殊边界继续有效，通用层只管价值去重和排序 |
