# srt-slice-copy｜SRT文案 C2 0.1.8 唯一规则版

本Skill支持SRT及逐条时长文本，保留片段功能、原序号和完整原话。统一触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。

## 时长规则

所有入选片段按1.2倍速播放后的预计成片保持45–90秒，质量允许时尽量接近70秒。原素材1.0倍对应54–108秒，目标约84秒；预计值=原始选段时长÷1.2，四舍五入到毫秒、半毫秒向上。原SRT时间码和逐条时长文本累计定位保持未缩放。未加速的片头、转场或停顿另计；纯SRT无法核实实际导出时长或加速后的语音清晰度。

## 使用

上传 `.srt` 字幕，或提供逐条时长文本（每行 `序号 秒数s 原话`），再输入触发词。完整可读的短文本直接处理；长附件、可能截断或累计复杂时，使用一次扫描、一次语义筛选和一次定稿核验。仅在质量条件满足时靠近70秒，不硬凑或重复卖点。五部分输出和抖音电商风险提示规则见 [SKILL.md](SKILL.md)。

短文本无需运行脚本；长文本或用户要求程序核验时使用 `scripts/srt_fast.py` 和 `scripts/render_compact.py`。未运行脚本时不报告程序核验通过。该Skill不处理MP4。
