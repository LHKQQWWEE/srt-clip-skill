# 女装与时尚配饰专项规则

适用于女装、常规服装、箱包及不属于鞋类/围巾配饰的时尚穿搭单品。鞋类由 `categories/shoes.md` 处理；围巾、围脖、丝巾、披肩和围领配饰由 `categories/scarves.md` 处理。以鞋或围巾为目标时，不叠加本文件的专项商品判断。

通用开头、中段、成交、时长、多条方案和输出规则只由 Universal Core 决定：`references/editorial-policy.md`、`references/highlight-selection.md`。本模块只保留时尚商品的属性、风险与归属判断。

## 外观、版型与搭配事实

- 服装/配饰的外观、穿着轮廓、肩线、腰线、衣长、视觉比例和搭配效果可形成不同购买理由；只有字幕原话明确表达的效果才能选用，不能凭未查看的画面补写显瘦、显高、显气色或遮肉结论。
- 颜色和搭配是否有购买价值看原话实际表达的顾客结果与使用关系。颜色名称、服装名称或“什么都能搭”本身不证明所有人/所有搭配都适用；不按关键词封禁或自动升级。
- 尺码、衣长、版型和选购建议保留其对象与条件；不把普通建议冒充顾客困扰，也不将主播个人偏好扩成普遍适配。
- 材质/成分、工艺、视觉质感、主观手感和穿着体验属于不同事实。没有商品资料时不把主播表述说成已核验事实；不从材质名推导含量、品质、功效或所有人适用。疑点按通用合规规则就地标待核实。

## 负面表现、安全与护理限制

- 顾客担忧、商品负面表现和主播回答按原话语境分别识别。主播明确确认商品有某项负面表现时，不把该表现反向包装成优点；用户明确要求制作答疑时仍须忠实原话，不补造解决效果。
- 安全风险、重要不适用人群、护理要求或实际限制不得剪掉后留下相反的无条件承诺。条件无法可靠表达时，相关正面承诺也不能脱离条件保留。
- 画面才能确认的试穿、版型或细节须就地标“画面待核实”；只有 SRT 时不声称已看过穿着效果。
- 全局禁用表述和平台审核案例只按 `references/global-rules.md` 执行，本类目不复制或扩展禁词范围。

## 商品、颜色与穿搭归属

- 顺带出现的外套、裤装、鞋包等可以解释目标商品的穿搭关系；其独立规格、材质或功能不能混入目标商品成片。
- 同款不同颜色可共享确实适用于各色的事实；颜色/款式专属的面料、版型、图案、搭配或外观效果只归对应选项。号码或价格仅在原话清楚指向款号/商品时辅助识别，不能单独当作归属证据。
- 同品牌、同系列或相似款不自动视为同一商品。商品切换、别称、长短款或具体链接边界不清时，按 Universal Core 核对上下文，仍不清楚则不作确定归属。

## 标题与类目固定话题

- 本时尚类目可以固定使用 `#穿搭`、`#时尚营销`；其余话题由 Universal Core 按当前商品和该版主线补足。
- 作品标题和话题不使用颜色名/配色组合，不写价格、库存、SKU、促销或未证实事实。标题与话题还须遵守全局规则中的禁词：不得出现“羽绒服”；该限制只作用于标题和话题，不要求删除正文真实原话。
