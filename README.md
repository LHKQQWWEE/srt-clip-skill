# SRT文案与SRT切片文案｜C2 0.1.8

本仓库唯一权威 Skill 位于 [`.agents/skills/srt-slice-copy/SKILL.md`](.agents/skills/srt-slice-copy/SKILL.md)。统一触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。

- 所有入选片段按1.2倍速播放后的预计成片为45–90秒，质量允许时尽量接近70秒。
- 原素材1.0倍对应54–108秒，目标约84秒；预计值=原始选段时长÷1.2，四舍五入到毫秒、半毫秒向上。时长门槛检查加速后的预计值。
- 原SRT时间码和逐条时长文本累计定位保持原素材口径、不缩放。未加速片头、转场或停顿另计。纯SRT无法核实实际导出时长或加速后的语音清晰度。
- 完整短文本直接处理；长、可能截断或累计复杂时，采用一次扫描、一次语义筛选、一次定稿核验与渲染。未执行脚本时不报告程序核验通过。
- 保留原字幕和序号，保证语义完整、至少两类独立购买理由和真实CTA；不硬凑或重复卖点。仅对入选字幕及标题/话题提示抖音电商风险，不作平台审核保证。
- 只处理SRT或逐条时长文本，不处理MP4；普通视频/原声判断保持独立。
