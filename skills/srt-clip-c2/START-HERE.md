# SRT Clip C2 Universal 0.4.7｜开始使用

Skill 版本：**0.4.49**；业务内核：**0.4.7**。本 Skill 同时支持抖音电商增长咨询与 SRT 文案剪辑。咨询协作见 SKILL.md；SRT 任务由本目录的 SKILL.md 进入。摘要缺失或无法确认有效时读取当前权威规则；工具边界仅限日常 SRT 剪辑：不调用 Python、脚本或 CLI，也不更新 JSON 摘要。电商咨询涉及最新平台规则或其他时效信息时，可按需查官方权威来源。

## 输入

- 触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。
- 输入为 SRT 或逐条时长文本。只有视频文件时不声称核验未读取的画面或原声。
- 同一 AI 完成语义分析和现有一次终检；日常 SRT 剪辑不调用 Python 或其他工具。

## 规则顺序

多商品先列商品身份与原始讲解窗口，等待用户选商品；未选前不生成开头候选。目标明确或仅一件商品时跳过商品选择。完整读取目标商品全部有效窗口并建立卖点池后，展示候选池内所有达到现有质量门槛且彼此实质不同的开头候选，不设识别或展示数量上限；每个只展示方案名称、开头原话、原始 SRT 序号、预估时长。不得遗漏合格候选、包装重复候选、预选、代选或凑数。用户最多选择三个；超过三个时暂停并要求重选。用户选择几个开头，就分别生成几条独立完整成片；每条必须从对应用户所选开头开始，并独立覆盖完整有效信息池。开头仍遵循动态观看动力优先级、前 2 秒/前 5 秒连续判断、1.2 倍速 2.4 秒/6 秒仅作参考、不硬截原话及其他现有有效规则。

先完成完整信息池；大致重复赞美按表达任务竞争并保留最佳原话，不按主题删减独立理由、体验、证据和场景。每条方案写正文前完成重复竞争与首次容量优化，首稿直接采用优化选段。全片统一按 1.2 倍速估算（预计成片时长 = 原始选段累计时长 ÷ 1.2），折算后 90 秒为目标。超过 90 秒比较当前方案的板块增量，仅可整块省略不含未覆盖独立卖点且不承担必要支持的低贡献补充板块。100 秒为非硬上限的可接受参考；超过 100 秒逐条复核，不自动截断。促单独立识别且不计入卖点支持或价值排序；适用且合规原话完整置于最后板块，结尾动态交易信息无活动例外，促单绝对化用语照常审核。最终终检只检查实际写出的成片。

原序号、原话和时长须按不可变映射逐条核对；第五部分序号与成片正文必须完全一致，否则阻断交付。日常正式交付保持原固定五部分；正式词库、商品识别、归属、动态结构和原话边界以运行正文为准。
