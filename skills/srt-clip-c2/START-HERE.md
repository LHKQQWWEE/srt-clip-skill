# SRT Clip C2 Universal 0.4.6｜开始使用

插件包版本：**0.4.26**；业务内核：**0.4.6**。从本目录的 [SKILL.md](SKILL.md) 进入。每次任务读取入口和唯一编译运行正文 `references/runtime-current.md`；普通素材任务不重复读取源文件清单或运行时 manifest。

## 输入

- 触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。
- 输入为 SRT 或逐条时长文本。只有视频文件时不声称核验未读取的画面或原声。
- 同一 AI 完成一次语义分析和现有一次终检；脚本是可选的机械辅助。

## 规则顺序

完整读取目标商品全部有效窗口并建立卖点池后，按共情优先顺序比较开头，只评估开头及必要紧邻回应。随后检测多视频机会；若用户没有指定单条或主题组合，主动建议数量与主题、保存当前对话检查点并暂停。用户选择后恢复，不重复读取、识别或检测。

每条实际选定的成片都须覆盖全部有效信息及必要证据/条件。适用且合规的原文促单完整保留；没有原文时不补造。时长只作约数参考，不参与验收、不触发拆条。最终终检只检查用户已选且实际写出的成片。

日常正式交付保持固定五部分；正式词库、商品识别、归属、动态结构和原话边界以运行正文为准。
