# 开头钩子、商品顺序与句级处理

处理开头、材质平台反馈、穿搭搭配、逼单话术或商品归属前，先读本文件。这里是这些编辑判断的唯一细则；`SKILL.md` 中的步骤只负责提醒调用，不另设一套排序。

## 开头：先识别候选，再比较吸引力

开头候选必须是目标顾客愿意听、原话完整自然、离开直播上下文也能理解的句子；它还要能接上同一商品的后续原话。候选包括有吸引力的外观表达、商品核心卖点和真实顾客困扰；这三类不是固定排序。先判断句子是谁在说、表达的是顾客的问题、主播评价、商品事实、穿搭建议，还是结尾话术，再比较吸引力、相关性、自然度和后续原话。不要把“困扰”这个标签直接当成排序结果。

按下面的规则筛选：

1. **外观表达可以是强候选。** 对服装、鞋包等外观消费品，完整清楚的“穿起来很好看”“显瘦又好看”等表达可以开头；女性服装中“好看”是有吸引力的外观理由。多个外观句都自然、强度相近时，明确说“好看”的句子优先于普通外观夸赞。无需凭画面替原话背书；若没有看过视频，只把语气和实际穿着效果列为未核实项。孤立的“好看！”、“你们看这个”等碎句仍不够完整。
2. **商品核心卖点可以胜过弱开头。** 用原话里辨识度高、归属明确的核心卖点；例如“新国标九五的鹅”与“三防面料工艺”可比身高/短款选购建议更适合作为羽绒服开头。卖点是否适合开头，要与其他合格候选比较，不因它是材质/工艺就自动第一，也不因有顾客困扰就自动排在后面。若商品资料可用，核对标准、成分和工艺；没有资料时，仍可把原话作为剪辑候选，但必须在对应片段注明资料待核实。不要补写原话没有的标准、含量或效果；已知不实或明确被拒审的说法按例外处理。
3. **顾客困扰也是有条件的候选。** 只有素材明确呈现顾客使用、穿着或购买时自己的烦恼，或主播清楚地复述/转述了顾客的烦恼，才进入候选；结合共鸣强度、句子质量及后面有没有相关原话判断。困扰确实最能打动目标顾客且有相关后续时可以开头；用户明确要多条方案时，也可把足够有吸引力的困扰放在另一条方案开头。困扰不必有保证解决问题的话术，但后面必须接与该困扰相关的原话，帮助顾客判断；无相关后续时，改用更合适的外观句或商品核心卖点开头，不能用无关“好看”或材质句冒充回答，也不能编造商品解决问题的效果。清楚且有信息价值的困扰原话仍可在后文保留为顾客需求，但要说明素材没有对应解释，不暗示商品解决了它，也不能仅因没有回应就把这项内容从亮点覆盖中删掉。
4. **没有合适候选时，** 选素材中最清楚、最有辨识度的商品事实；没有就如实说明，不用颜色搭配、尺码建议、促销或碎片口播凑开头。

### 认定顾客困扰

- 顾客自己说出的疑问、担心或穿用问题可以算，包括弹幕中的完整问题；例如“顾客弹幕：小个子穿这件会不会显矮？”可保留完整问题本身作开头，后面接原素材中的衣长、腰线等相关版型介绍。主播回答放在开头钩子之后，作为后续内容；不能把回答句单独当成顾客困扰，也不能把“问题＋回答”整体冒充一条顾客困扰钩子。
- 主播清楚概括“顾客担心……”“很多小个子担心……”时可作为候选；普通主播提问、主播自己的偏好或商品描述不能在没有语境依据时冒充顾客表达。“我喜欢这件”不能推成顾客喜欢；清楚表达“因为穿起来好看所以喜欢”的完整原话可按其实际意思评估。
- **顾客困扰说的是顾客会遇到什么，不是商品有什么问题。** “这种颜色比较怕流水印子”是在描述商品/颜色，不等于顾客担心；“浅色衣服容易脏，怕不好打理”若明确表达为顾客的使用烦恼，才可候选。尺寸、衣长、选长短款、选颜色、问如何搭配，通常是选购或搭配问题，不是开头痛点。
- 服装可考虑显矮、显臃肿、天冷仍怕冷、浅色易脏不好打理、担心花钱后穿着不好看等明确顾客烦恼；“怕闷热/出汗、衣服太重/肩膀累”或商品漏绒、钻绒、异味等质量投诉不自动成为开头痛点。鞋子“新鞋磨脚”可按完整语境判断；怕滑摔、脚痛或穿久累不作痛点开头。包袋的顾客困扰不作开头；围巾扎脖子/肤感问题不作开头。新情况按顾客实际表达和上下文判断，不把这些例子当作完整词表。
- 颜色搭配不是顾客痛点，也不作开头；“显白”或“显年轻”单独出现也不作为开头。完整表达若同时包含合格的显瘦/好看等吸引力，可保留原句中的其他修饰，不因出现颜色词而机械拆改。

### 句子完整、相关承接与方案差异

- 直接保留最完整、最能听懂的困扰句。只有“这个/它”等指代确实不清楚时，才把最短的必要前句一起放进开头；如果前文很长，找更短的困扰候选，或改用外观/核心卖点。
- 选定顾客痛点后，先接与该问题对应的商品讲解。例如显矮/显臃肿接衣长、腰线、版型；保暖担心接实际保暖讲解。对应主题完整讲完后再切换到材质或其他卖点；不要拿无关材质句替代版型回答。
- 不同开头候选都不强时，先换一段更短、更自然的原话，再考虑商品核心卖点。不要选读起来不通顺、需要猜错字、悬空的颜色词或“所以/但是”起头的半句。疑似转写错误保留原字并标回听，不代改。
- 只在用户要求的方案数内比较开头。默认一条；要求两条时可以分别采用最强的外观/商品卖点与另一条足够强且有相关承接的顾客困扰。两条近乎重复或没有第二个合适开头时不硬凑。

## 商品描述、搭配、选购与结尾

- 通常先完整讲清一个商品主题，再切换到另一个主题。按素材和开头安排，可以先讲开头对应的版型/材质主题；版型、材质各自讲完再进入下一类。不得因“衔接不顺”删掉有用的不同亮点；先找原话、调整顺序，仍需确认的在相应组标“衔接需回听”。
- 目标商品自身的描述讲完后保留所有不同的穿搭建议，包括不同裤型、裙装、鞋包或颜色组合；一起保留原话里的身高、天气、场合等适用条件。顺序可按商品内容放在版型/材质介绍后、尺码建议前。搭配建议里顺带出现另一件商品，不代表切换为介绍该商品；只保留搭配建议及直接解释该搭配的必要细节。例如“搭直筒牛仔裤也可以”是搭配建议；“裤腿不包身”只有在上下文确认它是在解释该搭配的条件时才保留，否则作为另一件单品的独立规格，不混入目标商品成片。
- 尺码与选购建议放在商品介绍之后。它们能帮助选择，但不因指向“小个子/高个子”就变成顾客烦恼或开头。
- 只有上下文确实表明是成片逼单/促成购买的话术，才把这段放在结尾。结尾保持自然。单独的价格、优惠、库存和稀缺数量不算结尾逼单，也不是必须覆盖的商品亮点；默认省略，除非用户要保留且当前信息已核实，此时放在商品讲解之后。若一个字幕序号里把赞美/商品信息与催单连在一起，整条序号统一放在结尾，不拆成开头与结尾，也不重复序号；其中的价格/库存要单独标记待确认，不能当作购买理由。发布前无法确认动态信息时，整条混合字幕不进入正式成片序号；在风险说明列出原序号和待核实项，不能只删其中一句。
- 购买者的真实反馈如“买过的姐妹都说好看”在来源清楚且表达有吸引力时可作开头候选；裸销售数字、复购量或单纯“买了”留在后段。明确无法核实的社会证明要标记，不扩写为所有顾客都喜欢。主播单说“大家都喜欢”不等于观众已表达喜欢。

## 平台指出材质/成分违规时的删除范围

平台反馈通常指向一个具体词或一句话。只按反馈指出的具体范围处理；“平台明确指出”与“尚缺证明/我觉得有风险”必须分开。

1. **先对照平台原词/原句与字幕上下文。** 若指出一个词，标出每个包含该词的完整句子；若指出一句话，标出该句的每次出现。不要因同属一种材质或都在同一段，推定别的词句也违规。例：反馈指出“白鹅绒”不自动覆盖另一个独立说法“九五的鹅”或“三防工艺”。
2. **删除单位是违规句子。** 一句话中有被指出的词，并且还带有其他可用信息时，仍删除这整句话；不能只把该词抠掉后保留同一句里的卖点。若同一条字幕包含几句彼此独立的话，只删除含违规内容的句子，其余完整、清楚的句子和相邻字幕继续保留。若整条字幕本身就是被指出的句子，则该条字幕不入片。
3. **不删整段/整组/同类材质。** 保留下来的句子逐条核查其商品归属、原文和事实依据；违规反馈不自动扩展到同段的其他字幕、同句以外的独立说法、标题之外的产品名称或全部材质卖点。寻找素材里现成的替代原话，不改写或绕审。
4. **同一字幕行内保留和删除并存时，** 原字幕仅作为来源定位显示，在紧邻备注中准确列出“保留原句：……；剪除句：……；句内剪点待回听/待核实”。不把违规句放入实际成片、标题或话题；句界或剪点未被音视频核实前，不声称已经精确切开，时长按整条字幕作保守估算。若句子无法可靠分开，整条字幕暂不入片，并说明只影响这一条来源。
5. **只缺证明或证据时，** 如果平台没有指出具体违规词句，且也没有已知不实或既往拒审记录，原话不因“可能违规”整段删除；具体说明需要核实的材质/成分资料。反馈只说“材质有问题”但没有具体词句或来源时，列出相关原话/序号并请求对应平台提示，不推定全部材质违规。
6. **字幕疑似转写错误时，** 如果上下文明显提示它可能是被标记词的错字，按“疑似命中”处理，只删除该疑似词所在句，并明确说是预防处理、原声尚未核实；不能写成平台已确认。若无法判断是不是该词，标出疑点及序号，不扩大到整段。

凡属句内处理，都保留原始序号的追溯关系；亮点覆盖表分别记录被删的违规句和实际保留的独立句子。被平台指出的词/句可以在视频方案之外的风险说明中为核对而引用，但不可出现在实际成片原话、标题或话题。

## 商品归属、事实冲突与话题

- 先认清主播正在介绍哪个商品。顺带出现的穿搭单品不是额外目标；明确切换后的其他款不混进当前成片。商品切换、别称和指代依据不够时查前后文，仍不清楚就标归属不明，不把它当成正式选段。
- 同品牌、同类的两件 95 白鹅绒羽绒服可合并作为羽绒服类商品候选，但必须在工作记录和成片中区分款式/商品事实，不能把一件的版型、长短或面料说成另一件的。不同品牌的羽绒服各自识别；鹅绒与鸭绒款分开。不同长短款若同一设计/同款系列可放同一候选，但具体版型与衣长仍按各款归属标清。
- 商品资料与主播陈述冲突时，先用可靠商品资料确认；没有资料能判定时，优先保留说得更清楚且适合成片的一段，并在计划外说明原始矛盾。分别属于短/长款的衣长数字不是互相冲突。相反的主观穿搭意见可并存，保留各自条件，不伪装成同一事实。
- 标题和生成话题聚焦商品、外观吸引力或商品卖点，不以颜色搭配作为开头式话题，不写颜色名/配色组合；“显瘦又好看”这类原话有支持的外观利益可用。不得加入平台明确指出的违规词句、价格、库存、促销、SKU或未证实事实。固定话题仍为 `#穿搭`、`#时尚营销`。
