# SRT Clip C2 Universal 0.4.2

一个 AI 通过组织式逻辑职责完成带货短视频购买决策剪辑。商品购买路径根据实际顾客问题、字幕证据、适配条件与独立理由动态构建。

- 总决策编辑负责统筹并在硬规则内裁决，也检查低完播时已选内容是否先给出明确价值与购买机会。
- 购买决策架构师判断最小充分购买单元、前置依赖和最早合理成交机会，不套固定类目模板。
- 商品事实与边界官核对归属、证据与全局禁令，可否决越界内容。
- 购买决策剪辑师按“价值建立→决策形成→成交机会→新价值→新决策→必要时再成交”重排原话，并先检查上下文依赖。
- 成片质量审计官在现有一次终检中加入非机械截断压力测试，不设固定秒数或比例。

以上为一个 AI 在一次语义分析中的分工；不增加模型、Agent、额外轮次、台账或日常工具门槛。商品知识包只提供事实提醒和边界。

用户可能在任何位置离开。完整理由须让陌生顾客理解具体结果/用途/问题，并有足够原话依据与必要条件；孤立属性、宽泛适配词或 CTA 不自动触发成交。理由成立后，立即寻找最早合理、自然且语境完整的原话购买机会；后续独立理由只在有必要时再推动，不增加劝买密度。后段主要补充确定性、回应顾虑和帮助适配/选择，不承担第一次说服。动态价格、优惠、库存、限时、直播专属福利、涨价和稀缺等仍按全局规则排除。

重复取舍依据语境中的信息增量、说服增量和时间机会成本，不依据相似词比例或固定重复次数。有效强调不得挤占更重要的独立购买理由；不得为达到45秒保留无价值重复。

正式输入为 SRT 或逐条时长文本；正式成片预计 1.2 倍速 45–120 秒，45–90秒优先，固定五部分输出，保留原话和来源序号。

唯一入口为当前 SKILL.md。详细规则位于 references/ 与 product-knowledge-packs/。
