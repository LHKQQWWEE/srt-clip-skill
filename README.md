# SRT Clip C2 Universal 0.4.7

插件包与 Skill 版本：**0.4.50**；业务内核：**0.4.7**。支持抖音电商经营咨询与 SRT 文案剪辑。咨询规则见 `skills/srt-clip-c2/references/commerce-advisory.md`；SRT 执行从 `skills/srt-clip-c2/SKILL.md` 进入。

- 电商咨询区分已知事实、推断与待核实项，给出有排序的优先建议、可直接使用的内容或可观察指标；重大既有工作流调整先给完整方案并等确认。涉及最新平台规则时按需核对官方权威来源。
- 多商品先确认目标商品；完整信息池完成后展示全部通过质量门槛且实质不同的开头候选，由用户选择；选择几个就生成几条独立成片，每条从对应开头开始。
- 每条成片先从完整信息池规划全部独立有效卖点及必要支持，写稿前完成时长预算、购买信息单元竞争和首次容量优化，首稿直接采用优化选段；板块动态编排且不跨板块穿插。全片按 1.2 倍速折算，90 秒为目标、90–95 秒优先、95–100 秒复核、超过 100 秒专项优化并复核；120 秒原始时长对应 100 秒播放复核线，必要且不可替代内容可说明依据后超时，不自动截断。
- 购买信息按信息单元竞争，不按主题粗暴去重；有效候选删除可追溯，每条成片独立复核信息覆盖。
- 直接行动型与种草/推荐型促单独立分类，适用且合规的完整原话置于最后板块；结尾动态交易信息无活动例外，促单绝对化表达照常审核。
- 正式词库按字段范围逐项执行；命中时仅排除完整字幕句。最终核对原话、商品归属、序号及时长，固定五部分纯文本交付，不引入画面辅助。

日常 SRT 剪辑不调用 Python、脚本、CLI 或 JSON 流水线；这些工具仅供开发、构建和发布验证。
