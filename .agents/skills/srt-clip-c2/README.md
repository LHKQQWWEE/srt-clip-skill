# srt-clip-c2｜直播切片文案 C2 0.2.4

本插件把 SRT 与视频切片工作流合并为一套现行规则。触发词为：**切片文案、srt文案、srt切片文案、str文案、C2完整精简版**。

## 输入路径

- **SRT / 逐条时长文本**：保留C2文本快路径，严格核对原话、原序号与来源定位；秒数的 `s` 后缀可省略，字幕原话完整保留。
- **MP4 + SRT**：先完整分析SRT，再对所有最终候选片段和必要歧义区间定向核验视频；不默认逐帧通览整段视频。
- **MP4-only**：只有当前宿主实际能读取口播、画面和时间定位时才制作；没有可靠SRT序号时不生成序号，无法可靠听辨时请用户提供SRT或带时间码的原话。

MP4本身不会自动启用语音识别或解码服务。技能只报告当前环境实际读取到的音画范围。视频不可读但SRT可靠时，可继续按SRT交付并明确画面/原声待核实。

## 时长与开头

统一按全部入选素材以1.2倍速播放后的预计成片45–90秒执行，质量允许时尽量接近70秒；原始素材定位保持1.0倍口径。开头优先复盘最终成片的5秒完播率；5秒是优化目标，不截断完整口播。

## 输出与真实性

固定五部分输出。保留完整原话；视频核验等级严格依据实际听辨和画面检查。长文本或程序核验请求使用随附SRT脚本；脚本不解析MP4。入选原话、来源时间、序号及合规提示都不得臆造。

## 长文本选段收口

附件或可能截断的文本扫描一次并输出完整清单，截断时从同一快照分页；仅完整可见、未截断的粘贴文本可用 `--summary`，完整解析和快照不变，只隐藏逐条扫描输出。完整读完后比较会影响质量的候选，不在第一个时长合格的方案处停止；完成商品/来源、语义衔接、原文支持、合规和时长检查后冻结。缺少钩子、独立理由或软性购买引导时如实说明。完整字段结构与例外条件见 Skill。

## 验证

```
python -S tests/test_portable.py
```

测试素材为合成数据，不含用户SRT或真实销售价格。

## 成片编排

以选购顾问和带货操盘手视角围绕商品与顾客需求确定主线，比较清楚自足的开头；中段以独立购买理由及原话解释承接利益，排除同义重复；结尾优先自然的软性购买引导，区分决策辅助和利益收束，缺项如实标明。前5秒按实际播放时间判断，数据复盘不保证成交。

## 异常素材

素材充分筛选后不足45秒时使用 `--allow-short-report` 输出明确标识非正式成片的候选，来源核验与时长不达标分别报告。正常模式仍严格执行45–90秒。
