# SRT Clip C2 Universal 0.4.6

插件包版本：**0.4.26**；业务内核：**0.4.6**。日常入口完整读取 `skills/srt-clip-c2/SKILL.md` 与唯一编译正文 `skills/srt-clip-c2/references/runtime-current.md`；清单、源映射和开发规则用于构建与验收，不作为普通素材任务的额外读取要求。

一个 AI 在一次语义分析和现有一次终检中完成购买决策与原话剪辑。先读完目标商品的全部有效窗口并建立完整信息池，再比较开头和检查多视频机会。

- 开头只比较开头及理解它所需的紧邻回应，优先有原话依据的真实顾客困扰或顾虑，其次是直接回应、具体可信的顾客收益和可验证商品事实；不比较完整成片。
- 完整信息池建立后才检测多视频机会。若存在可行主题且用户未指定单条或主题组合，先建议数量和主题，保存当前对话检查点并暂停；用户选择后恢复，不重复读取、识别或检测。
- 每条实际选定的成片都独立覆盖全部有效购买信息及必要证据、条件；多条并集不能补足单条遗漏。
- 适用且合规的原文促单必须完整保留；原文没有时，不编造、改写、补充或跨商品移用。动态交易内容仍按全局规则处理。
- 时长只作约数参考，不参与验收、不触发删点、补写或拆条。最终终检只检查用户已选且实际写出的成片。
- 固定五部分交付不变。正式禁词范围、商品识别与归属、重复识别、动态结构、原话真实性、AI-First 单 AI 架构及插件入口配置保持不变。
