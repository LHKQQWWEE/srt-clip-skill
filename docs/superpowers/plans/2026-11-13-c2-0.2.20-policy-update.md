# C2 0.2.20 Policy Update Implementation Plan

> **For agentic workers:** Use the inline execution workflow for this approved plan. Complete each task in order and keep the checklist current.

**Goal:** Update C2's opening, material moderation, styling, and ending decisions to match the user's confirmed editorial rules, then verify and synchronize the portable skill and private plugin.

**Architecture:** Keep one authoritative `SKILL.md`; put the detailed hook and sentence-level material decisions in one linked reference. Preserve the existing Python parser and render interfaces, and use manual scenario evaluation for semantic behavior plus the existing portable test suite for scripts and packaging.

**Tech Stack:** Markdown skill files, Python 3.10+ standard-library scripts/tests, ZIP plugin package.

**Spec:** User-approved full behavior proposal in the Codex conversation immediately before “确认修改”.

## Global Constraints

- Skill version is C2 0.2.20; private plugin version is 0.1.48.
- Material moderation targets the platform-identified word or sentence; remove the entire sentence containing a flagged word, retain independent clean sentences/cues, and never discard the whole paragraph by association.
- A customer pain is a candidate, not a fixed first choice; choose among natural appearance, core-selling-point, and customer-pain hooks using the user's stated preferences and context.
- Keep original source wording and IDs for traceability; when a flagged sentence shares one cue with a clean sentence, show only the clean sentence in the clip text and list the exact removed sentence in the source-exception coverage. Count the full cue duration conservatively and mark an unverified cut point.
- Validate the entire rendered clip section against the source-checked renderer so extra unnumbered text cannot reintroduce a deleted sentence.
- Treat any clearly expressed customer use/wear concern as a pain candidate regardless of product category; screen the customer's actual meaning and context rather than a fixed category list.
- Every requested version covers every distinct supported buying point; a different angle is not a reason to omit one.
- Preserve Python 3.10+ compatibility and the standard-library-only runtime.
- Synchronize the personal skill and the existing private plugin without changing its identity, audience, or integrations.

## Review Focus

- A customer comment is distinguished from a host's answer or a product-condition statement.
- One flagged sentence inside a multi-sentence subtitle does not erase independent clean sentences in that cue.
- “好看” appearance appeal can outrank a weaker pain hook; color coordination alone cannot become a hook.
- Size advice, product details, styling guidance, and CTA material land in the agreed sequence.
- No duplicate or stale rule still forces pain-first or whole-paragraph removal.
