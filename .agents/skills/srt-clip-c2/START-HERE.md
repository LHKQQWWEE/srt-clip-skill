# SRT Clip C2 Universal 0.4.7｜开始使用

Skill 版本：**0.4.41**；业务内核：**0.4.7**。从本目录的 [SKILL.md](SKILL.md) 进入。摘要缺失或无法确认有效时读取当前权威规则；日常任务不调用 Python、脚本或 CLI，也不更新 JSON 摘要。

## 输入

- 触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。
- 输入为 SRT 或逐条时长文本。只有视频文件时不声称核验未读取的画面或原声。
- 同一 AI 完成语义分析和现有一次终检；日常执行完全不调用 Python 或其他工具。

## 规则顺序

多商品先列商品身份与原始讲解窗口，等待用户选商品；未选前不生成开头候选。目标明确或仅一件商品时跳过商品选择。完整读取目标商品全部有效窗口并建立卖点池后，展示候选池内所有达到现有质量门槛且彼此实质不同的开头候选，不设识别或展示数量上限；每个只展示方案名称、开头原话、原始 SRT 序号、预估时长。不得遗漏合格候选、包装重复候选、预选、代选或凑数。用户最多选择三个；超过三个时暂停并要求重选。用户选择几个开头，就分别生成几条独立完整成片；每条必须从对应用户所选开头开始，并独立覆盖完整有效信息池。开头仍遵循动态观看动力优先级、前 2 秒/前 5 秒连续判断、1.2 倍速 2.4 秒/6 秒仅作参考、不硬截原话及其他现有有效规则。

先完整编排各方案，再分别计算时长。120 秒不是目标或硬上限；只有明显超过 120 秒才按该方案购买核心动态筛选并逐项说明省略项，必要时可适度超时。适用且合规的原文促单完整保留；没有原文时不补造。最终终检只检查实际写出的成片。

原序号、原话和时长须按不可变映射逐条核对；第五部分序号与成片正文必须完全一致，否则阻断交付。日常正式交付保持原固定五部分；正式词库、商品识别、归属、动态结构和原话边界以运行正文为准。
