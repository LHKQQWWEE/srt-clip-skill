# SRT Clip C2 Universal 0.4.7

Skill 版本：**0.4.39**；业务内核：**0.4.7**。执行入口见 `SKILL.md`；无效或缺失的持久摘要不作为规则依据，改读当前运行正文及权威规则。日常剪辑不调用 Python、脚本、CLI 或外部工具。

- 一个 AI 在一次语义分析和现有一次终检中完成全部判断。
- 多商品先列商品及讲解窗口并等待用户选择；选择后完整读取所选商品并建立信息池。目标明确或仅一件商品时跳过商品选择。
- 钩子与必要紧邻承接联合编排，综合判断前 2 秒吸引力和前 5 秒连续吸引力；默认 1.2 倍速对应原素材累计 2.4 秒/6 秒，仅作参考、不硬截原话。存在合格的开放式观看动力钩子时必须从中择优，仅在不存在时回退到其他有效钩子；按实际观看动力动态分类，不按卖点类别或名称机械判断，第一优先级内部无固定顺序、权重或评分。多方案可共享最佳钩子。
- 完整信息池后展示所有达到现有质量门槛且彼此实质不同的真实开头候选，不设数量上限；每个只含方案名称、开头原话、原始 SRT 序号和预估时长。不得遗漏合格候选、包装重复候选、预选、代选或凑数。用户最多选择三个；每个选中开头独立生成一条完整成片，每条独立覆盖完整有效卖点池和必要支持。
- 先完成全量编排再计算时长。120 秒不是目标或硬上限；只有明显超时才按本方案购买核心动态筛选并逐项说明省略项，必要时可适度超过 120 秒。
- 适用且合规的原文促单须完整保留；原文没有时不编造、改写或补充。
- 最终终检只检查实际写出的成片；原话、字幕序号、商品归属、禁词边界、风险提示、CTA、五部分输出和 AI-First 边界保持不变。
- 原始序号是硬验收红线：不可变序号/原话/时长映射、正文及第五部分序号必须逐项一致，否则不得交付。固定五部分交付、正式词库范围、原话和商品归属边界保持不变。

Python 工具仅供开发、构建与发布测试使用，不进入日常 SRT 执行。便携版由开发构建流程从当前权威规则生成。
