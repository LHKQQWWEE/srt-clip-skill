# SRT Clip C2 Universal 0.4.7

插件包与 Skill 版本：**0.4.45**；业务内核：**0.4.7**。除 SRT 文案剪辑外，也支持抖音电商商品、短视频、直播表达、流量、点击、成交和工作流咨询；咨询时区分已知事实、推断与待核实项，给出优先建议、行动和指标，重大工作流调整先确认方案。日常 SRT 入口见 skills/srt-clip-c2/SKILL.md 与唯一编译正文 skills/srt-clip-c2/references/runtime-current.md；日常剪辑不调用 Python、脚本、CLI 或 JSON 流水线。

一个 AI 完成语义分析和现有一次终检。多商品先列商品身份与讲解窗口并等待用户选择，再完整读取所选商品并建立信息池；目标明确或单商品时跳过商品选择。

- 开头按开放式观看动力优先级判断，结合紧邻承接评估前 2 秒和前 5 秒连续吸引力；1.2 倍速下 2.4 秒/6 秒仅作参考，不硬截原话。
- 完整信息池后展示全部达到质量门槛且彼此实质不同的开头候选，不设识别或展示数量上限。每项只含方案名、开头原话、原始 SRT 序号、预估时长；用户最多选择三个。
- 每个用户选中的开头各生成独立完整成片；先覆盖全部有效卖点，再按开放类别划分板块，允许板块内调序和板块间整块动态排序，禁止跨板块穿插。90 秒为目标，默认按 1.2 倍速估算；100 秒为可接受参考，超过后逐条复核且不自动截断，再按本条购买核心动态评估低价值完整板块。
- 促单独立识别，不计入卖点支持或价值排序。直接行动型与种草/推荐/购买信心强化型原话均识别；适用且合规时完整保留并置于最后板块。结尾促单排除动态价格、优惠、赠品、福利、倒计时和稀缺信息且无活动例外；促单绝对化用语照常审核。主体可核验且对应当前 SKU 的真实标价按既有规则处理。
- 0.4.44 完成第三阶段绝对化用语升级：大致重复话术按表达任务竞争，保留最佳原话与独立卖点；绝对化表达按商品语境精准拦截，首选不设个人意见或证明豁免；ASR 疑似项只提示，命中只排除完整句。
- 0.4.43 建立统一违禁词词库：区分直接命中、商品语境判断与未确认 ASR；先扫原始 SRT，成片复扫后核对原始序号。
- 适用且合规的原文促单必须完整保留；原文没有时不编造、改写、补充或跨商品移用。动态交易内容仍按全局规则处理。
- 不可变原始序号/原话/时长映射必须与成片正文和第五部分序号逐项一致，错误或无法核实即阻断交付。
- 最终终检只检查实际写出的成片；保留其他有效业务规则和固定五部分输出。
