# 直播切片文案 C2 0.2.20

默认生成一条覆盖全部已确认亮点的完整方案；用户明确要求多条但没有指定数量时先询问数量，指定后按要求生成，最多三条。开头比较吸引力强的外观表达、商品核心卖点和真实顾客困扰，不固定困扰优先。平台指出材质词句违规时，删除含违规内容的整句，保留同字幕里的其他独立干净句和相邻字幕。每个方案覆盖全部不同亮点；多方案可更换合适开头和顺序，不按侧重点漏项。穿搭、选购、逼单和材质句内编辑遵循 `references/editorial-policy.md`。每条方案提供一个标题、三个生成话题和固定话题 `#穿搭 #时尚营销`。五部分输出保留来源定位、亮点覆盖和同一代码框内以空行分隔的方案序号。只报告实际核验范围。
