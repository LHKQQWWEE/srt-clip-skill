# 直播切片文案 C2 0.2.8

统一处理 SRT、逐条时长、MP4+SRT 和可读取的 MP4-only；具体路由与五部分格式见 SKILL.md。优先输出三个不同开头的完整方案，综合推荐一个；素材不足时不硬凑，不固定理由数量或70秒目标。优先预计1.2倍速成片45–90秒，素材受限时大于30秒可成片；原话、来源、各方案序号及音画证据如实核对。

`references/qianchuan-offline.md` 保存千川与抖音电商公开规则判断要点和来源；日常离线，用户要求更新时才联网。不是禁词表或审核保证。

长文本运行随包脚本；程序来源核验不证明语义、合规或音画。30秒及以下可按 SKILL.md 使用短候选路径。

验证：`python -S tests/test_portable.py`、`python -S tests/test_multi_plan.py` 和 `python -S tests/test_duration_boundaries.py`。

默认优先规避羊毛、羊绒及相关含量、混纺与羊绒手感比较；鹅绒按用户实际经验正常作为候选。明确风险句可自然分离时只删该句；疑似字幕错字不自动拆断连续原话。仅依据字幕不能确认音画剪点。
