# SRT Clip C2 Universal 0.4.7

Skill 版本：**0.4.27**；业务内核：**0.4.7**。先检查与版本/源规则哈希绑定的 `references/execution-summary.json`。有效摘要可复用；摘要缺失、无效或版本/文件哈希变化时回读权威规则并刷新。

- 一个 AI 在一次语义分析和现有一次终检中完成全部判断。
- 先读完目标商品有效窗口并建立完整信息池，再做开头比较和多视频机会检测。
- 开头比较只评估开头与必要紧邻回应，按共情优先顺序，不生成完整成片比赛或评分。
- 默认直接生成两个购买核心独立、实质不同的完整方案。每条分别覆盖完整有效信息池和必要支持；第二条不能形成真实独立购买价值或会降质时单条交付并说明原因。开头指定“单条”或“按推荐版”时直接一条。
- 先完成全量编排再计算时长。120 秒不是目标或硬上限；只有明显超时才按本方案购买核心动态筛选并逐项说明省略项，必要时可适度超过 120 秒。
- 适用且合规的原文促单须完整保留；原文没有时不编造、改写或补充。
- 最终终检只检查实际写出的成片；原话、字幕序号、商品归属、禁词边界、风险提示、CTA、五部分输出和 AI-First 边界保持不变。
- 固定五部分交付、正式词库范围、原话和商品归属边界保持不变。

可选 `scripts/srt_tools.py` 仅做解析、原话组装和机械结构/直接命中核验，不代替 AI 的语义判断。工具不可用时可按“模型逐条对照”继续。

执行入口见 [SKILL.md](SKILL.md)，便携版由 `scripts/build_portable.py` 从当前权威规则生成。
