# C2 Universal 0.3.19｜质量验收标准

本标准按当前 `SKILL.md` 与有效 `references/` 验收；旧版本的历史结论不替代本版规则。

## 硬性门槛（任一实质失败即不通过）

- 原话被擅自改写、补造或拼接。
- 商品归属串用，或不同款式的事实混用。
- 伪造字幕编号、来源或时间。
- 单条方案1.2倍速预计时长超过120秒。
- 默认规则下把价格、优惠、赠品、直播间活动或库存等动态交易信息放入任一位置；混合话术发生改写、补词或不连续拼接。
- 全局禁用词句被错误保留，或禁用范围被擅自扩大。
- 误把缺少证明说成已知虚假，或虚称平台已拒审。
- 声称运行了实际未运行的程序、完整读取了未读取的文件或核验了未读取的视频。
- 固定五部分输出结构实质缺失。
- 把明显只对老粉/老顾客成立的限定话术误当成面向陌生流量的通用强钩子或首要成交节点，且没有可独立成立的社会证明/购买价值。
- 仅因为颜色、搭配、材质等“介绍完整”就让弱候选压过更强的顾客结果型钩子，且没有基于顾客相关性、即时收益、差异性、可信度和承接做合理解释。

## 质量评分（100分）

| 指标 | 权重 |
|---|---:|
| 商品识别与窗口归属 | 15 |
| 独立购买理由覆盖与重复处理 | 20 |
| 陌生顾客钩子吸引力与兑现 | 15 |
| 原话与序号准确性 | 15 |
| 时长计算与限制 | 10 |
| 顾客决策导向成交递进 | 10 |
| 合规风险判断 | 10 |
| 输出格式 | 5 |
| **总分** | **100** |

建议通过线：90分，且全部硬性门槛通过。平均分不能抵消硬性错误。

## 0.3.19 陌生顾客钩子验收

- 默认把第一次刷到、不了解主播和直播背景的陌生顾客作为第一优先级；老粉兼顾，不作为默认首要受众。
- 钩子类型不设固定排序；统一比较顾客相关性、即时收益、差异性、具体可信度和后续承接。
- 差异性是加分项，不是硬门槛；强普遍需求如果具体、可信、可兑现，仍可成为最佳钩子。
- 纯颜色、泛泛“好看/洋气”、直播过渡、链接/库存、老粉限定表达默认降级；不能按关键词机械封禁。
- 颜色若直接带来明确顾客结果且确实赢过其他候选，可以做钩子；否则更适合作为中段卖点或选择信息。
- 强钩子必须能被同一商品原话最小充分兑现，不能只有“炸点”没有解释/证据。
- 内部陌生顾客测试属于同次语义判断，不得升级成新的日常流程节点、模型轮次或强制表单。

## 0.3.19 成交验收

- 开头兑现且至少一个购买理由成立后，选择对陌生顾客也自然有效的最早合理成交机会。
- 价值确认、适配/选择、决策简化、行动引导按实际语义判断，不依赖“买/拍/入/拿”关键词。
- 老粉/老顾客限定成交话术默认降级；不能让陌生顾客明显感觉“与我无关”却仍作为通用首要成交节点。
- 首次成交后继续覆盖独立购买理由；后续成交只有新增转化价值时保留。
- 弱成交、重复行动引导和强直播背景话术不得挤占独立卖点时长。
- 不设固定成交次数、位置、软硬比例，不强制结尾逼单；没有高质量成交话术时可以自然结束。

## 购买理由与信息增量

- 有新增购买决策信息的不同类型卖点均进入候选；主题或类别差异不得成为淘汰理由。
- 去重看新增信息，不看类别；同类不同事实应分别保留。
- 开头、承接与结尾按素材自然编排；逻辑关系只辅助排序，真实反差仅轻量加权。
- 超时先删同义重复、无信息夸赞、弱/重复成交、低价值内容和已充分覆盖的次级信息；独立有效卖点最后才因硬上限舍弃。
- 不得新增日常流程节点、模型轮次、Python前置、卖点JSON台账或大纲要求。

## 0.3.19 单条最优、多条互补验收

- 默认单条先保证成片自身停留、说服和购买决策质量，再在节奏与时长允许时覆盖独立有效购买信息；不为提高覆盖率硬塞低价值内容。
- 明确要求多条时，每条都应独立成立；不同方案可以共享不可替代的核心购买理由，并将次要有效理由分配给更匹配的方案。
- 多条在主要购买理由、需求角度、中段组合或决策路径上应有真实价值差异；只换开头而长期复制主体不通过。
- 不为降低重复而削弱强方案，不为凑覆盖或凑数量拼入弱信息；素材确实不足时如实说明。
- 明确要求2—3条而素材只能支撑较少数量时，交付可独立成立的高质量方案，并在第三部分简要说明数量限制。
- 不以机械重复率、覆盖率或覆盖矩阵替代语义判断，不新增普通任务阶段、台账、第二轮扫描或模型轮次。

## 动态交易与合规验收

- 价格、优惠、赠品、直播福利、倒计时、库存、稀缺数量等动态交易信息默认全片排除；仅用户明确要求有效期明确的活动素材且确认发布条件时才有单任务例外。
- 混合字幕仅允许保留原话中连续、语法完整且意思自足的完整子句；仅剩词组或残句时舍弃整条相关字幕，不得改写、补词或拼接。
- 全局禁用表述仍按完整原始字幕序号排除；不得因新钩子策略放宽禁用规则。
- 缺证明不等于已知虚假；字幕文本不能证明实际画面、音频、商品页或质检。

## 长文本与 AI-First 验收

- AI必须保留语义决策权；工具只可辅助机械读取、定位、计算。
- 工具不可用时，只要文本可可靠读取，核心剪辑任务不得被阻断。
- Long Context Mode必须保证目标商品全部离散窗口被读取；购买信息筛选、钩子竞争和编排仍在同次语义处理中完成。
- 多方案共享同一次商品归属、购买信息与合规判断，不重新全文扫描或另建卖点池。
- 2000条/约2小时的结构压力用例必须能处理，不要求Python作为日常运行前置。

## 测试报告必须区分

- 规则/结构静态检查。
- 当前 AI 对真实/历史样本的实际语义测试。
- 程序实际执行测试。
- 不同 AI 平台的独立兼容测试。

未实际运行的类别标记“未测试”，不得推断跨模型兼容已经通过。

## 不变约束

- AI-First；卖点决定“留不留”，结构决定“怎么排”。
- 原话、商品归属、1.2倍速120秒、类目专项、固定五部分继续执行。
- Universal话题不向非时尚类目泄漏；女装/鞋/围巾模块仍可使用其现有固定话题。
