# 开放式钩子优先级回归 · Skill 0.4.30

## 验收范围

本回归使用真实素材原话，核对钩子优先级、动态归类、无第一优先级候选时的回退，以及前 2 秒/前 5 秒连续吸引力和多方案共享开头规则。语义判断为人工回放，脚本只检查规则与文件一致性，不判断钩子质量。文本判断不声称平台实际完播或转化提升，也不证明音画效果或整条成片通过。

## 当前规则的单一路径

1. 先完成目标商品全部有效窗口读取与完整信息池，再建立“真实钩子＋必要紧邻承接”的开头候选单元。
2. 先检查候选的原话真实性、商品归属、合规、自然理解和后文兑现等硬边界。按候选单元在当前目标顾客语境中实际形成的观看动力动态归类；不按卖点类别、类型名称或关键词机械判断。
3. 只要存在合格的开放式观看动力驱动型候选，就必须在这一组中动态择优。候选类型开放、举例不构成穷尽列表；第一优先级内部不排固定顺序，不设权重或评分。
4. 仅当合格的第一优先级候选为零时，才从其他有效钩子中择优；也没有有效候选时，如实说明，不拼凑开头。
5. 把同一开头单元放在前 2 秒吸引力与前 5 秒连续吸引力中联合判断。默认 1.2 倍速对应原素材累计 2.4 秒与 6 秒，仅作参考；不得硬截完整原话或必要承接；承接动力须由当前原话和后续关系动态决定。
6. 多方案可共享同一最佳钩子；只有当该开头不适合某方案或不能由该方案后文兑现时，才为该方案另选开头。

## 回归场景

### A. 真实外套素材中的优先选择

用户来源的鹅绒服逐条时长文本：第 1 条“品牌色是这个灰咖色”；第 11–15 条“比如说你觉得现在的羽绒服都做得轻飘飘 / 薄薄的那种，轻飘飘的 / 你需要一件比较抗风的啊 / 又比较耐造的 / 你可以选这一件”。

预期：第 11–15 条在文本语境下形成反差、需求关联与商品回应，属于观看动力驱动候选；若后文能兑现该回应，就必须优先从合格的观看动力候选中选择，不得因为第 1 条先出现或属于颜色信息而越级选它。不能把“外套”“抗风”之类卖点类别直接当作第一优先级标签。

回放结果：PASS。候选顺序不取代资格和观看动力判断；首句对照没有覆盖第一优先级候选。

### B. 同一商品类型内的动态归类

小马甲的既有真实字幕摘录：第 8–9 条“这个马甲我跟你们说 / 我真的好喜欢这个马甲”；第 17–18 条“小手往这里口袋这么一插 / 我觉得真的是好看的不得了”；第 61–64 条“你看到这个菱格了吗 / 你再看一下背后 / 对整体的这个型 / 很好看，很好看”。

预期：按实际原话动力区分情绪感染、动作/审美展示、视觉好奇与设计吸引；这些候选并非因“马甲”这个商品类别自动同类，也不建立情绪、动作或设计之间的固定先后。不同候选的紧邻承接和 2/5 秒连续性决定本次选择。只凭字幕不能确认动作确已发生、画面效果或主播真实情绪。

回放结果：PASS。类型随原话和承接动态判断，未把名称当成入选条件；音画效果均标为未核验。

### C. 不同商品表达下的跨类型归类

真实鞋类字幕第 35–44 条：“我给我管它叫心机鞋 / 为什么叫心机鞋呢 / 因为它是内增高 / 它里面自动给你增高这么高 / 就是得有7厘米 / 六七厘米吧 / 嗯 / 它得自动增高六七厘米 / 看一下子啊 / 它里边是内增高”。

预期：“心机鞋”一词本身不自动获得优先资格；若“为什么这样叫”与后续高度说明共同产生好奇、反差或具体体验期待，则整个开头单元可归入第一优先级。按其观看动力择优，不因它是鞋类、功能信息或某个类型名称作固定判断。

回放结果：PASS。实际观看动力决定归类；类型名称与商品类别本身不触发优先。

### D. 无第一优先级候选时回退

控制组使用同一外套素材的真实原话“品牌色是这个灰咖色”。把它作为候选仅用于验证零第一优先级分支：如果完整目标商品范围内没有合格观看动力驱动型候选，且该颜色句对当前目标顾客确有兴趣、可独立理解并可由后文支持，则可作为其他有效钩子中的备选；否则不得硬把它判为有效或拼凑开头。

回放结果：PASS（条件分支）。完整鹅绒服材料另有合格观看动力候选，因此本条在该完整材料中**不触发回退**；控制组只验证当合格第一优先级候选数为零时才回退的规则，不冒充一轮完整素材的优胜结果。

### E. 双窗口连续性与 1.2 倍速参考

真实鞋类字幕第 35–38 条累计原素材时长为 6.80 秒；第 35–36 条合计 3.32 秒。默认 1.2 倍速下，前 2 秒参考约落在第 36 条表达过程中，前 5 秒参考约落在第 38 条表达过程中。

预期：保留完整自然表达与解释“心机鞋”的必要承接，以开头单元联合判断两个窗口的吸引与延续。2.4 秒和 6 秒不是硬剪辑点；不得硬切或硬截完整原话，不得为了贴点截断第 36 条或第 38 条。

回放结果：PASS。保留完整必要原话；时间参考不转成资格线或剪辑点。

### F. 多方案共享最佳钩子

以小马甲原话“我真的好喜欢这个马甲”作为共享开头控制例：若两个不同购买核心的方案都能自然承接该真实表达，且各自后文能兑现，允许共用；不为制造表面差异强制换成不同类型。若其中一条不相关或无法兑现，则只为该方案另择合格开头。

回放结果：PASS。购买核心影响主体排序，不自动触发开头替换。

## 结果边界

本回归覆盖了观看动力候选优先、跨商品表达的动态分类、条件式回退、前 2 秒/前 5 秒连续判断、默认 1.2 倍速参考、原话不硬切及多方案共享开头。多瑙河素材和小马甲素材在当前环境中仅有会话片段/既有摘录；除鹅绒服和鞋类来源文本外，未取得这两份素材的完整 SRT，因此不宣称已完成它们的全信息池回归或整条成片验收。
