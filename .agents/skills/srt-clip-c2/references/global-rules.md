# 全局用户指定规则

本文件适用于所有商品类别，优先级高于任何类别专项模块。

## 固定全局禁用词句

当前用户明确指定的跨商品禁用表述：

1. **“三醋酸羊绒羊毛”**及明确变体：允许空格、换行、标点差异；也识别在“三醋酸”和“羊绒羊毛”之间插入“的”的说法，例如“三醋酸的羊绒、羊毛”。
2. **“桑蚕丝、绵羊毛、山羊绒的混纺”**及明确变体：允许空格、标点、“和/与/及”等连接词及“的”字差异，但必须表达这三种材质共同构成混纺。

边界：
- 命中时删除包含该表述的完整句，不只抠除词语。
- 不把禁用范围扩大到独立的“三醋酸羊绒”“羊绒”“羊毛”，也不扩大到只出现其中一种或两种材质但未表达指定混纺组合的句子。
- 若同一字幕含有彼此独立的完整句，且句界可靠，可保留未命中的独立句；句内剪点未被音画核实前必须标记待回听。
- 被禁用的原句只能在明确标记为“已排除”的例外说明中用于追溯，不能出现在成片原话、标题或话题。
- 以后用户明确新增的禁用词句默认跨所有商品生效；若用户同时明确限定某个商品或素材，则按该限定执行。
- 这些是用户指定的剪辑规则，不得表述成抖音对所有商品的普遍禁词结论。

## 标题与话题限制

- **“羽绒服”不得出现在任何商品的作品标题和生成话题中；只限制标题、话题，不限制正文原话、商品识别或风险说明。**
- 每条方案恰好一个标题和五个话题。话题必须与当前商品、类目和该版主线相关，彼此不得重复。
- 已加载类目模块可以指定最多两个类目固定话题；通用核心生成剩余话题补足五个。没有专项模块时，通用核心生成五个相关话题。
- `#穿搭`、`#时尚营销` 只属于女装/时尚配饰专项模块，不是 Universal 全局固定话题。
- 标题和话题必须由原文支持，不编造材质、成分、功效、价格、库存、稀缺或效果承诺。
- 不以颜色名或配色组合单独充当标题主线或生成话题。

## 明确未设置的全局禁令

- 不存在“所有100%或100％材质表述一律禁止”的全局规则。具体材质含量按证据和平台实际反馈逐项评估；缺少证明时标记待核实，不擅自把它升级为用户指定禁词。
- 不得把单个被指出的材质词扩大成整类材质或整段禁用。
