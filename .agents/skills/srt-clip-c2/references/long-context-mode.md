# Long Context Mode｜AI-First 长文本模式

## 目标与边界

在数百到数千条字幕、数十分钟到数小时直播文本中，确保文本和目标商品窗口不被截断或漏读。长文本模式只管理读取覆盖和商品边界；商品理解、购买价值判断、去重、筛选和编排仍由 AI 完成。分段读取是输入管理，不是新增模型轮次或额外语义复查。

## 何时自动启用

不设置“超过N条就必须调用Python”的工具门槛。全文一次读取有明显截断、遗漏、上下文污染或商品反复切换风险时启用；约1000条以上是强信号但非硬阈值，2000条、接近2小时的素材直接启用。工具不可用时，AI 仍按可读范围处理。

## 读取与编排

1. **确认覆盖与商品窗口**：按可用读取能力覆盖全文并识别商品切换、别称、款式与目标商品的离散窗口。分段之间保留必要边界上下文。窗口地图只帮助定位和确认覆盖，不包含强制卖点台账。
2. **逐个目标窗口完成同次语义处理**：阅读目标商品窗口时，直接判断商品归属、必要上下文、合规边界和每段内容的购买信息增量；在同一次语义处理中筛选并考虑自然顺序。不另设主题分析、卖点池建立、遗漏扫描或先大纲后成片阶段。
3. **围绕购买信息组织成片**：独立有效信息不因类别或主题不同而删除。同义内容按新增信息去重；效果与原因、顾虑与回应、特点与价值等关系仅帮助排序。真实反差可以加权，不制造原文不存在的冲突。多方案共享同一次商品归属、语义取舍和合规判断。
4. **时长装配**：汇集一次语义处理选出的片段，按现行时长规则计算。超时裁剪依据 highlight-selection.md，独立有效卖点最后才因时长不足舍弃。

## 一次终检

使用 final-check.md 对成片的来源、商品归属、原意、条件、顺序、时长、合规和输出格式进行一次终检；不再次通读完整目标窗口来另做遗漏检查。若发现输入范围确有缺口，只补读缺失范围；这属于读取完整性修复，不是卖点复查。

## 工具降级

分段文件读取、序号/时间码定位、时长累计可作为可选机械辅助，必须把语义判断留给 AI。缺少工具不构成失败；只有文本无法取得、范围存在无法补齐的缺口或关键来源无法确认时，才如实说明受限。
