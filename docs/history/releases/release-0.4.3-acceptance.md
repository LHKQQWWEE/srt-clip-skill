# C2 Universal 0.4.3 Release Acceptance

- **Baseline:** installed C2 Universal 0.4.2, verified from the active Skill entry and its references.
- **Target:** C2 Universal core 0.4.3; plugin package 0.4.10.
- **Scope:** dynamic duration, qualitative important-reason coverage, and proactive notice of independent multi-cut opportunities.
- **Preserved:** dynamic content structure, earliest natural purchase opportunity and low-completion checks, contextual repetition judgment, one-AI organizational responsibilities, AI-First operation, user-authorized prohibited-term boundary, source wording, and fixed five-part output.
- **No change:** no new Agent, model round, mandatory tool, or daily workflow step.

## Rule acceptance

- General 1.2x lower-bound guidance is 45 seconds. Shorter material can qualify only when the actual source is genuinely short and the cut independently meets purchase-reason, evidence/condition, attribution, continuity, and no-padding requirements.
- There is no fixed maximum duration. 120 seconds is neither a trim ceiling nor a split trigger.
- Important independent purchase reasons are checked qualitatively in the existing semantic pass. No 100% coverage target, percentage, ledger, matrix, or second full-text scan.
- One best cut remains the default. If two or more distinct paths are independently supported, the output proactively notes the available directions within Part 3. Full alternatives are generated only when the user asks.

## Real-source regression

- **Source:** 粘贴的文本 (1)(5).txt, a real user-provided line-by-line transcript with 609 numbered cues and 827.115 seconds of total cue duration. Target product: the fully wrapped Birk-style shoe / concealed-height shoe.
- **Default output test:** selected one best 49-cue path with 79.559 seconds of source time, estimated 66.299 seconds at 1.2x. It covers concealed height, wedge comfort/rebound, outfit use, width/instep fit, textile/leather construction and care, lining/warmth conditions, and size range without trying to approach 120 seconds.
- **Proactive multi-cut test:** the same source independently supports an additional “height and outfit” path (55.666 seconds) and a “wide-foot fit and autumn/winter wear” path (50.199 seconds). The updated default reports those directions as available but returns only the 66.299-second best cut unless the user requests the alternatives.
- **Coverage judgment:** the selected cut preserves distinct decision reasons and necessary warmth conditions. Conflicting size advice is excluded; live price/promotion/stock-dependent lines are not detached from their context. Cue IDs and cumulative durations are checked against the source.
- **Duration interpretation:** this real shoe sample does not need more than 120 seconds. That does not reinstate a cap; the no-cap rule is independently checked in the active policy, final-check contract, manifests, and automated rule tests.
- **Short-material boundary:** existing 31.067-second and 12.750-second excerpts are partial windows used for repetition testing, not evidence that a full product source qualifies for the short-material exception. They remain non-release examples.
