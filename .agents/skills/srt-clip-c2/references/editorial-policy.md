# 通用开头、承接、结尾与原话规则

本文件适用于所有带货类目。若商品存在已建立的类目模块，同时读取该模块；类目模块只能补充本文件，不能覆盖全局原话、来源、合规和时长规则。

## 开头候选

- 开头候选必须与目标商品相关，原话完整、自然，脱离直播上下文后仍能理解，并能承接同一商品的后续内容。
- 默认把**第一次刷到视频的陌生顾客**作为第一判断对象，老粉兼顾但不主导。候选包括：吸引人的外观/使用效果表达、商品核心卖点、真实顾客困扰、可信的购买者体验、具体版型/设计价值和材质体验。它们**不设固定类型排序**；统一比较顾客相关性、即时收益、差异性、具体/可信度、句子完整度和后续承接。**差异性是重要加分项，不是硬门槛**；即便“显瘦/好看/利落”等不是独家卖点，只要原话具体、对陌生顾客有强收益且后续可兑现，仍可成为最佳钩子。
- 不要把“顾客困扰”标签直接当成排序结果，也不要把主播回答、主播个人偏好或一般选购建议伪装成顾客表达。
- 顾客自己提出的完整疑问或困扰可以作为候选；主播清楚转述顾客担忧时也可作为候选。主播回答应放在问题之后，不能单独冒充顾客问题。
- 顾客困扰必须表达顾客实际购买、使用或体验中的烦恼；商品属性本身、普通尺码建议、搭配建议、主播提问或泛泛描述不自动构成顾客痛点。
- 若主播明确确认目标商品确实存在顾客担心的负面表现，该困扰和确认性回答默认不入片、不作开头。用户明确要求围绕该问题制作答疑时例外，仍须忠实原话，不暗示商品能够解决它。
- 纯颜色名/配色、普通搭配、一般尺码建议、泛泛材质名、孤立“好看/洋气”等如果没有马上转成顾客收益，默认属于普通或弱钩子；它们不是绝对禁用。完整原话若把颜色等属性直接转成显气色、不沉闷等明确结果，并且实际竞争力更强，仍可参与开头竞争。链接、价格/库存/活动、直播过渡、强依赖前情以及只对老粉成立的表达原则上不作通用首钩。\n- 不得编造顾客问题、商品效果、用户评价或后续解释。没有合适开头时，选最清楚、最有辨识度的商品事实；仍没有则如实说明，不用促销、颜色词或碎片口播凑开头。

开头确定后，优先寻找能解释、证明或展示其核心吸引点的原话。以下关系只帮助判断语义承接，不是分类模板，也不要求穷尽：

| 开头价值 | 可优先寻找的支撑内容 |
|---|---|
| 好看、颜值 | 上身效果、版型、材质质感、设计细节 |
| 显瘦、显高 | 剪裁、版型、身材修饰、视觉比例 |
| 材质特点 | 材质表现、触感、质感、实际穿用体验 |
| 穿着舒服 | 柔软度、弹性、亲肤感、真实穿着体验 |
| 搭配好看 | 颜色关系、搭配方式、不同穿搭效果 |
| 保暖 | 面料特点、真实保暖表现、穿着场景 |
| 解决困扰 | 困扰原因、原文中的解决方式及可支持的效果 |
| 性价比、价值 | 商品本身的价值构成；不依赖实时价格、优惠或赠品 |

采用**最小充分承接**：优先选最有说服力且足以兑现开头的原话，不要求全部出现相关卖点；不连续堆砌同义表达，不因开头主题而延长前半段。若素材支撑不足，应重新权衡开头，而不是拼凑解释。具有独立购买价值的其他卖点继续进入后续编排。

## 原话与语义

- 原话必须逐字保留；命中全局禁令时按完整原始字幕序号排除（不进行句内拆分）；其他非禁令的选段规则照旧，不得润色、改写、拼接造句或补充商品事实。
- 允许重排同一商品的原话，但必须保持对象、条件、因果和原意。不能跨商品拼接。
- “它/这个/那款”等指代不清时，先查必要前后文；仍不能确认商品归属则不入正式成片或明确标待核实。
- 连续原话整体可理解、只是疑似字幕识别错字时，优先原样保留并标记回听；不能仅凭错字擅自改写或拆句。
- 开头或片段若依赖“所以/但是/因为”等前文，补最短必要上下文或换更自然的候选；无法解决则不作为正式方案。
- 衔接困难不等于可以删除有价值的不同亮点。先寻找替代原话、调整顺序；仍需确认时保留并标“衔接需回听”。

## 中段与多卖点编排

- 开头之后先接足以兑现开头核心价值的最小充分内容，再自然容纳其余独立有效卖点。带货成片可以同时包含多个信息类别，不要求全片只围绕一个主题。
- “同一主题先讲完”只可用于避免打断一个问题的直接回答，不是卖点筛选或删除规则。主题先后只影响编排，不决定卖点去留；结构暂时不好排、与开头角度不同，也不能作为淘汰独立购买信息的理由。
- 搭配、颜色、使用场景、规格、尺码、护理方式、适用人群及限制都可能有独立购买价值；是否保留看它提供的信息增量和现行时长约束。
- 不同事实不能仅因同属一个类别而合并。去重只按是否新增购买信息；同义表达可择优保留，同一卖点最多再留一处有实质强化价值的原话。
- 效果→原因、问题→解决、顾虑→回应、特点→使用价值、属性→场景、版型→效果、材质→体验、设计→功能、人群→适用理由可辅助重排，不是硬模板。真实反差只作轻量加权，禁止编造冲突。
- 开头价值获得充分支撑且至少一个实际购买理由成立后，优先选择原文中**对陌生顾客也成立的最早合理的成交机会**；不为等到所有卖点讲完而推迟，也不为追求更早位置而牺牲必要承接。成交话术不限定软硬程度或功能类型；价值确认、人群/尺码适配、款式/颜色选择、决策简化和行动引导都可按实际语义承担转化作用。
- 第一次成交之后继续考虑尚未覆盖的独立购买理由。后续成交节点仅在增加新的转化价值时安排；成交次数、位置及软硬比例动态决定，不设置双逼单或固定中段成交，也不要求结尾逼单。
- 搭配建议中顺带提到另一件商品，不代表当前目标商品切换；只保留搭配关系和解释该搭配所必需的内容。另一件商品的独立规格不能混入当前商品方案。

## 动态成交引导与动态交易信息

- 成交话术是否入选由其语义和新增转化价值决定，不靠“拍/买/入/拿”等关键词识别。它可以承担价值认同、购买建议、人群/尺码适配、款式/颜色选择、决策简化、行动引导或总结收口；不要求固定类型或顺序，不设置固定次数、位置或软硬比例。\n- **限定老粉话术**（以及“老顾客/复购用户”等限定人群话术）默认降级，**不是禁止**，但默认不作为面向陌生流量的优先成交节点；只有当前素材明确面向该人群，或同一句对陌生顾客也提供独立完整的购买决策价值时，才按实际价值参与竞争。弱成交话术、重复劝买和强依赖直播前情的行动引导不得挤占独立有效卖点。
- 具体商品价格、原价/现价对比、限时优惠、优惠券、满减、赠品、直播间福利、倒计时、库存/稀缺数量、最后一天、即将涨价及其他依赖实时交易条件的信息，全局默认排除，不得进入开头、中段、任何成交节点或结尾。普通批量切片始终采用这一默认规则。
- 仅当用户明确要求制作有明确有效期的活动素材，并确认价格、活动条件和实际发布时段仍有效时，才对该任务例外处理。此规则是长期素材的选片边界，不代表平台将这些内容认定为违规。
- 商品本身的设计、材质、版型、体验、搭配、场景及其他不依赖实时交易条件的购买理由仍可保留。笼统的商品价值表达不能因“价格”字样被误判为动态交易信息，但不得借价值表述带入具体实时价格或优惠。
- 同一字幕同时包含动态交易信息和商品卖点时，只有在排除动态部分后，剩余内容仍能逐字对应**完整原话子句**，且该子句是原始连续表达、语法与语义完整、脱离被删除交易条件后仍可独立成立并与成片衔接自然，才可只选该子句并保留原始序号。仅剩词组或残句时不保留残句，应舍弃整条相关字幕。不得改字、补词或拼接不连续片段；若完整子句依赖前文，只在已选内容能自然承接时使用。
- 本条混合话术处理不改变 `global-rules.md` 的禁令边界：命中全局禁用表述时，仍须排除完整原始字幕序号。
- 结尾可以用商品展示、有效价值总结、自然购买建议或有行动指向的原话；没有合适的成交话术时自然收口，不强制逼单，也不为传统结构破坏衔接。

## 社会证明与事实

- 购买者真实反馈在来源清楚、原话完整且表达有吸引力时可以作为候选；裸销售数字、复购量或单纯“买了”不自动构成有力开头。
- 主播泛称“大家都喜欢”不等于真实顾客反馈。无法核实的社会证明要标记，不扩写为所有顾客都喜欢。
- 历史价格、库存、售后、链接、销量或活动不代表当前事实。不得将其写成当前承诺。
- 安全风险或明确不适用人群信息不能被悄悄删除或弱化；保留完整原话并标明需要核实的适用条件。若同条原始序号命中全局禁用表述，则全局禁令优先排除整个序号。
