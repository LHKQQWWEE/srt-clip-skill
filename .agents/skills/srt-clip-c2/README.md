# SRT Clip C2 Universal 0.4.6

一个 AI 在一次语义分析中通过现有职责完成带货短视频购买决策剪辑。先完整读取目标商品上下文、识别全部有效独立购买信息并控制粒度，再比较完整候选路径。

- 单条和每条多视频方案都须覆盖全部有效独立卖点及必要证据/条件；方案并集只作额外一致性检查。
- 用户未指定数量时，先推荐可成立的多视频数量与主题，并等待用户选择后再正式生成多条方案。
- 直接禁词按唯一词库扫描，只排除实际命中的完整字幕。`羊毛`为正式禁词；`羊绒`单独出现、防静电和相邻字幕不连带命中。
- 时长不作为任务完成条件；45 秒一般下限参考、短时长质量例外和无固定上限均保留。
- 可选脚本只做字面直接匹配，不取代 AI 的语义、商品事实或卖点覆盖判断。

执行入口与完整规则见 [SKILL.md](SKILL.md)，便携版见 [C2-Universal-Portable.md](C2-Universal-Portable.md)。
