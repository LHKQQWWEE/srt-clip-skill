# SRT Clip C2 Universal 0.3.20｜开始使用

当前唯一执行版本为 **0.3.20**。只使用本目录的 `SKILL.md` 及它引用的文件；不从同名旧副本、旧 portable、旧启动提示或缓存内容中加载规则。

## 支持范围

- `.srt` 字幕文件
- 逐条时长文本（每行：`正整数编号 秒数s 原话`，也可省略 `s`）

MP4 不属于 0.3.20 正式跨平台范围。SRT 与 MP4 同时提供时只按 SRT 做文本剪辑，不声称核验画面或原声；只有 MP4 时，请先提供 SRT 或逐条时长文本。

## 四个触发词

`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。通用触发词 `切片文案` 不是 C2 触发词。

## 唯一执行规则

- Universal Core 是通用结构权威：陌生顾客首屏价值、强弱候选竞争、购买决策链和首次购买决策闭环按 `references/editorial-policy.md` 执行。
- 高/中/弱决策价值、单条覆盖、多条购买路径互补、信息密度和时长按 `references/highlight-selection.md` 执行。
- 类目文件只用于商品专项判断；全局合规、Long Context、终检和更新分别按对应 `references/` 文件执行。
- 正式成片预计 1.2 倍速 45–120 秒；45–90 秒优先，90–120 秒只在仍有独立高决策价值信息时扩展。低于45秒先检查可用高/中价值理由；仍不足则标记短候选，不凑时长。
- 固定五部分交付，保留原话和来源序号；第三部分仅解释核心理由、关键补充和重要未采用内容及原因。
- AI 完成一次语义分析和一次终检。普通任务不依赖 Python、外部服务、JSON 台账或额外模型轮次。

原生 Skill 用户安装整个目录；文件导入用户使用当前 ZIP；纯文本用户使用 `C2-Universal-Portable.md`。这些入口均只执行 0.3.20。
