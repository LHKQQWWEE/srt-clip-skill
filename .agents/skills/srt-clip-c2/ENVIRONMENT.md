# C2 Universal 0.3.14｜运行环境

- **普通任务不要求 Python。**
- 不需要安装第三方依赖，不需要网络或远程服务。
- SRT 和逐条时长文本由当前 AI 宿主的文件读取与文本分析能力处理。
- 复杂计算、文件读取或来源核验确有必要时，AI 可以使用宿主提供的计算器、代码执行或其他工具；这些工具是可选增强，不是普通任务前置条件。
- 0.3.14 不包含 MP4 解码、ASR 或音画核验能力；视频能力后续按平台单独适配。
- 测试脚本只用于开发/发行验收，不在每条日常任务中运行。
- 工具不可用时，按 SKILL.md 的降级规则执行并如实说明核验范围。
- **Long Context Mode 同样不要求 Python。**长文本可使用宿主分段读取或其他机械辅助，但语义判断始终由AI完成；工具不可用时，只要文本仍可取得，就按AI分块流程继续。
- 版本治理：未来升级遵守 `references/update-protocol.md`，不增加普通任务前置步骤。
