# SRT Clip C2 Universal 0.3.14｜开始使用

## 支持范围

首版跨平台正式支持：
- `.srt` 字幕文件
- 逐条时长文本（每行：`正整数编号 秒数s 原话`，也可省略 `s`）

MP4 不属于 0.3.14 正式跨平台范围。若只有 MP4，请先导出 SRT 或逐条时长文本；若同时提供 MP4 和 SRT，本版本只按 SRT 做文本剪辑，不声称核验画面或原声。

## 四个触发词

以下四个触发词等价：
- `srt文案`
- `srt切片文案`
- `str文案`
- `C2完整精简版`

通用触发词 `切片文案` 不属于 C2 触发词。

## 三种使用方式

1. **原生 Skill**：将整个 `srt-clip-c2` Skill 目录安装到支持 Agent Skills 的 AI Agent。
2. **文件导入**：向支持 Markdown/文件上传的 AI 上传本 ZIP 或整个 Skill 目录，并要求读取 `SKILL.md` 及其引用的 `references/`、`categories/`。
3. **纯文本模式**：将 `C2-Universal-Portable.md` 全文提供给 AI，随后粘贴 SRT 或逐条时长文本。

## 运行原则

- AI 主导；普通任务默认不需要 Python、环境测试或外部服务。
- 商品类别自动识别；已建立专项模块时加载，未建立时使用通用核心。
- 只对确实存在的歧义提问，不要求用户填写过程台账。
- 每条方案按 1.2 倍速预计不超过120秒。
- 固定五部分输出；保留原话和原始序号。
- 未实际读取的视频、未执行的程序或未核实的事实，不能声称已通过。
- Long Context Mode：超长文本按商品窗口确保读取覆盖；商品判断、卖点筛选与编排在同一次语义处理中完成，不另建卖点池或漏检阶段；不强制依赖Python或环境。
- AI-First Constitution：所有语义决策必须由AI完成，工具只能辅助机械读取/定位/计算。
- 开头默认面向第一次刷到视频的陌生顾客；钩子类型不设固定排序，必须有顾客收益与后续承接。
- 成交节点按是否推进购买决定判断；限定老粉话术默认降级，弱成交不挤占独立卖点，不强制结尾逼单。
- 版本治理：未来更新按 `references/update-protocol.md` 审核，不增加普通任务负担。

- 全局违禁词仅依据用户提供的违规审核截图或明确指定词句更新；所有商品统一执行，命中时排除整个原始字幕序号。
