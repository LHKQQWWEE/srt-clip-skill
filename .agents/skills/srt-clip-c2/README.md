# SRT Clip C2 Universal 0.4.4

一个 AI 通过组织式逻辑职责完成带货短视频购买决策剪辑。先识别目标商品全部有效卖点，再按每条成片自己的核心购买角度独立重评完整卖点集。

- 总决策编辑负责统筹、在硬规则内裁决，并确认全部卖点识别与逐条角度重评完成。
- 购买决策架构师按商品、顾客问题、字幕证据和每条方案的核心购买角度动态评估完整卖点集，不套固定类目模板。
- 商品事实与边界官核对归属、证据与全局禁令，可否决越界内容。
- 购买决策剪辑师按单条尽可能完整、多条差异化组合并整体覆盖的原则编排原话，并保留必要条件。
- 成片质量审计官在现有一次终检中核对逐条复评、覆盖、来源准确、误杀与越权扩围。

以上为一个 AI 在一次语义分析中的分工；不增加模型、Agent、额外轮次、台账或日常工具门槛。商品知识包只提供事实提醒和边界。

单条成片尽可能完整覆盖目标商品有效卖点。多条成片围绕各自核心购买角度差异化组合，并尽可能整体覆盖。每条都独立重评全部卖点，不沿用另一条的价值排序。购买推动是可选项；不得为开头或假设截断点强制提前 CTA。动态价格、优惠、库存、限时、直播专属福利、涨价和稀缺等仍按全局规则排除。

重复取舍依据语境中的信息增量、说服增量和时间机会成本，不依据相似词比例或固定重复次数。有效强调不得挤占更重要的独立购买理由；不得为达到45秒保留无价值重复。

正式禁词只排除命中的完整字幕序号，不连带上下文；相似字词或风险提示不能扩大命中或淘汰整段。正式输入为 SRT 或逐条时长文本；45秒为一般下限参考，短素材质量合格可例外，无固定时长上限，固定五部分输出，保留原话和来源序号。
