# 0.4.3 重复语义人工金标准案例

这些案例是开发验收夹具，不会在日常剪辑中新增分析步骤。测试内容来自 0.4.0 使用的 656 条真实字幕；公开包只保留必要的短句和序号，不包含原始完整文件。字幕编号及文本按来源保留。

|---|---|---|---|---|

## 人工重排结果

**鞋类重测（原窗口 1–149）**：`19,21,22,25,26,27,48,34,35,37,38,102,103,106,140,141,143,144,145,146,147`。预计 1.2 倍速 **31.067 秒**，该窗口只是609条鞋类长素材中的局部测试片段，不代表素材本身短；不能使用短时长类目例外，应继续结合完整商品窗口判断。单独隔离该窗口时只作重复语义测试，不作为正式成片交付。20 删除、21 保留；不留机械或过度重复凑时长。字幕 143–146 保留因果和穿袜条件。全羊毛成分宣称和动态交易信息仍按原规则排除；第47条防滑未验证，未使用。

**裤装强调重测（原窗口 497–507）**：`497,498,499,501,502,504,506,507`。预计 1.2 倍速 **12.750 秒**，只作重复/强调语义测试，不据此认定完整素材符合短时长例外；保留 497–498 的说服性强调，删掉 500、503 两处重复。不同商品窗口没有混编。

本夹具测试的是人工确认的源句归属、删留结果和时长账，不声称脚本能独立理解语义。程序回归只能锁定已审定案例；发布前仍须检查完整真实编排和取舍理由。
