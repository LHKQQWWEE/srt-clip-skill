# SRT Clip C2 Universal 0.3.6

AI 主导的跨平台带货视频文本剪辑 Skill。首版正式支持 SRT 与逐条时长文本，覆盖所有带货类目；通用核心与类目专项模块分离。

## 核心特征
- 四个固定触发词：`srt文案`、`srt切片文案`、`str文案`、`C2完整精简版`。
- 不使用通用触发词 `切片文案`。
- 默认不调用 Python，不创建强制 JSON 台账，不执行多轮工作流门槛。
- 自动识别商品类别并加载已建立的专项模块。
- 1.2倍速预计成片时长不超过120秒。
- 保留原话、原始序号、商品归属和完整亮点盘点。
- 固定五部分输出。
- 离线合规基线仅在用户明确输入“更新违禁词”时联网更新。

## 唯一规则入口
从 `SKILL.md` 开始；详细规则按需读取 `references/` 和 `categories/`。本 README 不另设业务规则。

- Long Context Mode：超长文本采用全局扫描→窗口地图→目标精读→单一卖点池→反向漏检→一次分析多方案；不强制依赖Python或环境。
- AI-First Constitution：所有语义决策必须由AI完成，工具只能辅助机械读取/定位/计算。

- 版本治理：未来升级遵守 `references/update-protocol.md` 的六项审查与三条一票否决（仅针对开发/发布，不增加日常执行负担）。
