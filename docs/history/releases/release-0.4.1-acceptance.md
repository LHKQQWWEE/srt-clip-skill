# C2 Universal 0.4.1｜完整升级、语义验收与发布记录

## 基准与范围

- 唯一业务基准：已安装并生效的 C2 Universal 0.4.0。目标版本：0.4.1。
- 0.4.1 只调整既有购买决策架构师、购买决策剪辑师、总决策编辑和成片质量审计官的重复判断/取舍责任；不新增角色、Agent、模型轮次、强制工具或工作流节点。
- 0.4.0 的组织式职责架构、AI-First、动态购买决策、原话/商品归属/合规、Long Context、1.2 倍速 45–120 秒（45–90 秒优先）和固定五部分输出继续有效。
- 正式时长不足45秒时先看是否有可自然加入的独立购买价值；仍不足则标短候选。机械/过度重复不得用于填充45秒。

## 新增的重复判断机制

同时判断信息增量、说服增量和被占用的时间/注意力机会成本；不按词语相似度或固定重复次数机械删减。

| 类型 | 裁决 | 真字幕验收例 |
|---|---|---|
| 机械性重复 | 优先删掉口误、卡顿、半句重启；完整、自然的重述保留。 | 鞋20“你不会觉得”删；鞋21“你不会觉得你是穿了一双毛的鞋子”留。 |
| 强调性重复 | 信息相同但能明显加强记忆、确定感或感染力时允许保留；与独立购买理由和节奏比较。 | 裤497“对，显高显瘦”接498“真显高显瘦”均留，供实际语义检验。 |
| 递进性重复 | 增加原因、证据、体验、条件、程度或选择帮助时优先留。 | 鞋140–147保留试穿松量、内里压缩、穿袜体验和宽/肉/胖脚尺码条件。 |
| 过度性重复 | 已充分表达且没有明显信息/说服增量时压缩成最有力的完整原话。 | 鞋34–36留34–35、删36；裤499–502留499、501–502、删500。 |

有效强调不因“和前一句意思一样”而自动删除，但也没有优先豁免权：若占用时间会挤掉更重要的尺码条件、顾虑回应或其他独立购买理由，须取舍。0.4.1 没有固定强调次数或相似度阈值。
