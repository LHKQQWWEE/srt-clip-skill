# C2 Universal 0.3.17｜发布验收记录

日期：2026-11-17

## 版本范围
- 基准版本：C2 Universal 0.3.16。
- 当前版本：C2 Universal 0.3.17。
- 本次业务更新：亮点覆盖升级为“单条最优、多条互补”；同一卖点“两处原话”上限明确为单条方案内部去冗余；多方案核心理由可共享，次要有效理由优先互补。
- 用户指定方案数量按“目标数量”执行，最多三条；素材不足以支撑时只交付能够独立成立的最大数量，不为凑数量制造弱方案。
- 不新增日常 Python、卖点台账、覆盖矩阵、第二轮遗漏扫描、模型轮次或新执行阶段；1.2 倍速 / 120 秒硬上限和固定五部分保持不变。

## 合规与全局禁用库
- 唯一执行库仍为 `references/global-rules.md`。
- 本次将当前已确认的全局禁用库完整同步进便携版，未根据一般风险、历史未确认提议或模型推测新增禁用词句。
- 实施过程中发现一条未最终确认的历史“不起球”禁用提议曾被临时带入；在发布前已撤回，并增加收尾检查，防止未确认提议进入现行全局库。
- 动态价格、优惠、赠品、库存等仍按编辑策略全片默认排除，不把该时效规则冒充平台禁词。

## 真实文本语义实测
- 使用用户文件库中已存在的真实逐条时长直播字幕进行私有语义测试；不把原文、商品专属 cue、选段范围或样本专属时长写入公开发行文件。
- 多卖点长窗口可形成明确不同的购买决策方向：修饰/适配、保暖/防风、耐用/实用细节；默认单条能够在不塞满120秒的情况下覆盖多个独立购买理由。
- 两条方案能够共享必要核心理由并让次要亮点互补，没有出现“只换开头、主体复制”的问题。
- 第三方向含较多需要证据支撑的功能/耐用表述，现有规则能够保留“待核实”边界；若关键内容无法可靠支撑，则不得为了指定数量硬凑正式方案。
- 同一真实素材的短窗口压力测试不足以形成正式时长时，按现行规则保留为短候选，不生成多个弱正式方案。
