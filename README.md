# SRT Clip C2 Universal 0.4.7

插件包版本：**0.4.28**；业务内核：**0.4.7**。日常入口完整读取 `skills/srt-clip-c2/SKILL.md` 与唯一编译正文 `skills/srt-clip-c2/references/runtime-current.md`；清单、源映射和开发规则用于构建与验收，不作为普通素材任务的额外读取要求。

一个 AI 在一次语义分析和现有一次终检中完成购买决策与原话剪辑。先读完目标商品的全部有效窗口并建立完整信息池，再比较开头并编排方案。

- 开头只比较开头及理解它所需的紧邻回应，优先有原话依据的真实顾客困扰或顾虑，其次是直接回应、具体可信的顾客收益和可验证商品事实；不比较完整成片。
- 默认直接生成两个具有真实、独立购买核心的完整方案；每条都从完整信息池独立编排，不能靠两条的并集补足遗漏。若第二条不能形成独立购买价值或会降低质量，只生成一条并说明原因。开头指定“单条”或“按推荐版”时直接生成一条。
- 先完整编排各方案，再计算时长。120 秒不是目标或硬上限；未明显超时保留全部有效卖点，明显超时才按该方案核心动态筛选并说明省略项。
- 适用且合规的原文促单必须完整保留；原文没有时，不编造、改写、补充或跨商品移用。动态交易内容仍按全局规则处理。
- 最终终检只检查实际写出的成片。执行摘要与原始规则文件校验匹配时可复用，不要求每次完整重读所有规则；摘要失效或遇到不确定、冲突时回查原文。
- 固定五部分交付不变。正式禁词范围、商品识别与归属、重复识别、动态结构、原话真实性、AI-First 单 AI 架构及插件入口配置保持不变。

完整运行约定见 [START-HERE.md](START-HERE.md)，日常入口见 `skills/srt-clip-c2/SKILL.md`。
